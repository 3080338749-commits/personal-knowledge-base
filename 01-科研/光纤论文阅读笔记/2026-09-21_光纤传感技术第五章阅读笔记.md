# 《光纤传感技术》第五章阅读笔记：相位调制型光纤传感器

## 1. 阅读背景

今天读第五章时，主要想弄清楚三个问题：外界物理量怎样变成光的相位变化；几种干涉仪的光路有什么区别；探测器测到光强后，怎样恢复待测信号。学习时先抓物理过程和结构，再理解解调方法，最后看实际应用。

## 2. 第五章总主线

```text
被测量 → 光程或两束光的传播时间发生变化 → 相位差变化
      → 干涉输出变化 → 光电探测与解调 → 得到被测量
```

相位通常不能直接由普通光电探测器读出。干涉仪让相干光重新叠加，把相位差转成可测的光强变化。随后还要处理工作点漂移和光强波动，才能稳定地恢复信号。

## 3. 第一层：相位调制基本原理

光在长度为 $L$、有效折射率为 $n$ 的光纤中单程传播，其相位可写为：

$$
\phi=\frac{2\pi nL}{\lambda_0}
$$

其中 $\lambda_0$ 是真空波长。温度、压力、应变或振动使 $L$、$n$ 或两者改变，就会引起光程 $nL$ 和相位变化：

$$
\Delta\phi=\frac{2\pi}{\lambda_0}\Delta(nL)
$$

两束光干涉时，输出光强中含有与 $\cos(\Delta\phi)$ 有关的项。因此，本章最基本的信号链是：**外界扰动 → 相位差 → 干涉光强**。反射式结构要计入往返光程，不能直接套用单程长度。

## 4. 第二层：典型光纤干涉仪结构

3 dB 光纤耦合器可先理解为分光和合光的器件。四种结构的关键区别是光怎样走、在哪里重新叠加。

| 结构                       | 光路与干涉方式                    | 记忆点                         |
| ------------------------ | -------------------------- | --------------------------- |
| Michelson（迈克尔逊）          | 分成参考臂和传感臂，两路光在末端反射，返回后合束   | **分光—反射—返回干涉**；传感臂的扰动经历往返传播 |
| Mach-Zehnder，M-Z（马赫-曾德尔） | 第一个耦合器分光，两臂向前传播，第二个耦合器合束   | **两条臂向前走**；可从两个输出端口检测互补信号   |
| Sagnac（萨格纳克）             | 两束光沿同一个光纤环顺、逆时针传播，回到耦合器后干涉 | **同环反向传播**；旋转会产生 Sagnac 相位差 |
| Fabry-Perot，F-P（法布里-珀罗）  | 两个反射面构成腔，光在腔内多次反射并叠加       | **看腔长和腔内介质变化**；可观察光强或干涉光谱   |

Michelson 和 M-Z 都容易用“参考臂与传感臂”理解，但前者是反射往返，后者是向前合束。Sagnac 比较同一环内反向传播的光。F-P 则主要关注两个反射面之间的腔。

## 5. 第三层：信号解调与补偿

### 零差检测与 2×2、3×3 耦合器

零差检测使用同一光源分出的相干光进行干涉，从输出信号中恢复相位。仅有一路 $\cos(\Delta\phi)$ 型光强时，在干涉条纹的峰或谷附近，小相位变化只引起很小的光强变化，还可能难以判断相位变化方向。

- **2×2 耦合器**可提供两个通常互补的输出，便于差分检测，抑制部分共同的光功率波动。但仅靠两个互补输出，不能自动得到完整的正交相位信息。
- **3×3 耦合器**可提供三个具有不同相位偏置的输出；理想对称情况下，相邻输出的相位偏置约为 $120^\circ$。联合处理多路信号，有助于恢复相位并减轻单一路输出的工作点问题。

具体效果仍取决于耦合器、探测器和实际解调算法。

### 正交工作点与 PZT 补偿

若把干涉项简化为 $I\propto\cos(\Delta\phi)$，则在 $\Delta\phi\approx\pi/2$ 的位置，曲线斜率最大，微小相位变化最容易表现为光强变化。这就是这里说的**正交工作点**。

温度和环境扰动会使两臂的基准相位缓慢漂移，工作点可能离开正交位置。PZT（压电陶瓷）受电压驱动会产生微小形变；将光纤绕在 PZT 上，可以通过改变光纤光程调节参考臂相位。闭环反馈可据此把工作点拉回合适位置。PZT 的调节行程有限，漂移过大时还需要处理复位或相位跳变。

## 6. 应用部分

### 光纤水听器

水下声压作用于传感结构和光纤，使光纤长度、有效折射率或两者变化；干涉仪把相位变化变成光强变化，解调后得到水声信号。多个水听器还可以组成阵列。相关内容可继续对照 [[周鑫淼_基于参数估计的光纤水听器PGC解调算法_第二章笔记]]。

### 光纤电流传感器

被测电流产生磁场，磁场通过**法拉第效应**改变光的偏振状态；检测偏振旋转或相应的光学信号，即可估计电流。它的关键机制是磁光效应，不能简单归结为“电流把光纤拉长”。光纤绝缘，适合电力系统中的电流测量。

### 光纤陀螺

光纤陀螺利用 Sagnac 效应：同一光纤环内的顺时针和逆时针光在环旋转时产生传播时间差及相位差；解调该相位差可得到旋转角速度。光纤绕成多匝可增强有效环路面积，提高旋转信号。

## 7. 给师兄汇报可用的简短总结

> 今天主要读了《光纤传感技术》第五章。我的理解是，相位调制型光纤传感器先把外界量变成光的相位差，再通过干涉把相位差转成光强，最后用解调方法恢复被测量。Michelson 是两臂反射往返，M-Z 是两臂向前合束，Sagnac 是同一光纤环内反向传播，F-P 是腔内多次反射。实际检测还要解决工作点漂移和相位衰落，可利用正交工作点、PZT 反馈或多路耦合器输出。应用上，水听器测声压引起的光程变化，电流传感器利用法拉第效应，光纤陀螺利用 Sagnac 效应测旋转。

### 第五章总框架

```text
外界物理量 → 改变光纤长度 L 或折射率 n → 改变光程 nL
→ 产生相位变化 Δφ → 通过干涉仪变成光强变化 I
→ 光电探测器输出电信号 → 解调恢复相位 → 补偿干扰
→ 得到真实被测量
```

其中最重要的是中间的“光程—相位—光强”转换关系。光在光纤中传播时，相位与光程 `nL` 有关；温度、压力、应变、声压或旋转等外界因素改变 `n`、`L`，或者改变两束光的传播时间，就会产生相位差。干涉仪把相位差转换成光强变化，光电探测器只能先测到光强，最后还需要解调才能得到相位或被测物理量。

### 四种典型干涉仪总结

- **Michelson 迈克尔逊干涉仪**：属于反射式结构。光经耦合器分成参考臂和传感臂，在末端反射后沿原路返回，再由同一个耦合器合束。传感臂的长度或折射率变化会带来往返光程变化，因此相位变化中包含往返传播的作用。它的优点是结构直观、器件数量相对少；需要注意反射端和回波稳定性。
- **Mach-Zehnder 马赫-曾德尔干涉仪**：由两个分光或合光器件和两条独立光路组成。第一处耦合器分光，光分别经过传感臂和参考臂，第二处耦合器重新合光。外界量主要作用在传感臂，参考臂用于比较。它适合说明“参考量与被测量之间的相位差”，但两条臂都可能受到温度和振动影响。
- **Sagnac 萨格纳克干涉仪**：同一个光纤环中有顺时针和逆时针两束光。静止时两束光的传播条件基本对称；光纤环旋转后，两束光的传播时间不同，形成与旋转角速度有关的 Sagnac 相位差。因此它主要用于光纤陀螺和旋转测量。
- **Fabry-Perot 法布里-珀罗干涉仪**：两个反射面形成一个光学腔，入射光在腔内多次反射，多个反射光束叠加形成多光束干涉。外界压力、温度或位移改变腔长，或者改变腔内折射率，就会引起干涉强度或干涉光谱变化。它体积小、灵敏度高，但腔长和光谱解调通常需要更精细的处理。

最短记忆：Michelson 来回走；M-Z 分两路走到底；Sagnac 绕圈反着走；F-P 腔里来回弹。

区分方法可以只问两个问题：第一，光是不是在末端反射返回；第二，两束光是不是在同一个环中反向传播。反射返回的是 Michelson，同环反向传播的是 Sagnac；两臂向前传播再合束的是 M-Z；两个反射面之间多次反射的是 F-P。

### 解调部分总结

- **解调的目的**：从探测器得到的光强信号中恢复相位变化，再根据标定关系换算成压力、应变、位移、旋转或电流等物理量。解调不是简单地“把电压变回相位”，还要处理非线性、周期性、噪声和相位跳变。
- **单路 `cos(Δφ)` 不好解**：余弦是非线性的，同一个光强值可能对应多个相位；相位增加和减少时，某些位置的光强变化方向也不容易判断；在峰值和谷值附近斜率接近零，小相位变化不明显；系统工作点还会随温度和振动漂移。
- **正交工作点**：对 `I∝cos(Δφ)` 而言，`Δφ≈π/2` 附近的斜率绝对值较大，光强对相位最敏感。把系统维持在这里，可以提高小信号灵敏度，但它本身不能解决所有的周期性和大范围相位变化问题。
- **工作点漂移**：温度、振动、光源变化和偏振状态变化会改变两臂的基准相位或干涉对比度，使系统偏离正交点。结果可能是灵敏度下降、输出失真，甚至出现相位突跳。
- **PZT 调相**：PZT 通电后发生微小伸缩。将光纤或反射镜安装在 PZT 上，可以改变光纤长度或等效光程，从而调节相位。它既可以在反馈回路中把工作点拉回正交位置，也可以主动加入周期性相位载波，作为 PGC 的调制器。
- **2×2 耦合器解调**：两个输出通常具有互补关系。对两路信号做差分或归一化，可以削弱光源功率共同变化带来的影响，提高抗强度噪声能力；但两路本身未必提供完整的正交 `sin/cos` 信息。
- **3×3 耦合器解调**：三路输出具有不同的相位偏置，理想情况下相邻输出约相差 `120°`。把三路信号按一定关系组合，可以构造出近似正交的相位信息，因此不必严格依赖单一工作点，适合连续相位恢复。
- **PGC 解调**：主动加入高频相位载波，使干涉信号在载波频率及其谐波附近产生可分离的频谱成分。提取一次谐波和二次谐波后，可得到与相位有关的两路信息，再用反正切计算相位。PGC 的优点是动态范围较大、适合数字处理；代价是需要调制器、滤波、采样和参数标定。
- **反正切与相位展开**：反正切根据两路正交量求出一个主值相位，通常落在 `-π` 到 `π`。当真实相位连续变化并跨过边界时，会出现人为的 `2π` 跳变；相位展开根据相邻采样点的连续性把这些跳变接起来。

今天需要记住的关系是：2×2 主要帮助做互补和差分，3×3 主要提供多路相移信息，PZT 主要负责调相和维持工作点，PGC 主要通过主动载波扩大可解调范围。

### 补偿部分总结

- 解调解决“怎么从光强读出相位”，补偿解决“怎么让读出来的相位更接近真实被测量”。因此，补偿既可以在光路和结构上实现，也可以在电路和算法中实现。
- **光源功率波动**：会让所有探测器输出一起变大或变小，容易被误认为相位变化。常用差分、归一化、自动功率控制或参考通道削弱这一共同变化。
- **工作点漂移**：会让系统离开最灵敏位置。可以使用 PZT 反馈、闭环控制、PGC 或 3×3 多路输出减少对固定工作点的依赖。
- **偏振扰动**：偏振态变化会使两束光的偏振不再匹配，造成干涉对比度下降，严重时出现衰落。可以使用保偏光纤、偏振控制器或偏振多样性接收结构。
- **温度漂移**：温度同时可能改变折射率 `n`、光纤长度 `L` 和器件相位，因此会产生与被测信号混在一起的慢变化。可以进行温度标定、增加参考传感器或采用差分结构。
- **机械扰动**：传感器外部的振动、弯曲和连接器松动会引入额外相位变化。可以通过隔振、封装、缩短非传感光路和结构补偿减小影响。

补偿的判断顺序可以是：先确认变化来自光源、工作点、偏振、温度还是机械结构，再选择差分、反馈、保偏、参考通道或隔振等方法。

### 应用部分总结

- **光纤水听器**：被测量是水下声压或声波。声压作用于膜片、光纤或封装结构，使光纤长度 `L`、有效折射率 `n` 或两者发生变化，形成随时间变化的相位信号。经过干涉、探测和解调后，得到水声波形。这里要区分环境温度和静态压力造成的慢变化，以及声波造成的动态变化。
- **光纤电流传感器**：被测量是电流。电流产生磁场，磁场通过法拉第效应改变光的偏振状态，系统再检测偏振旋转或相关相位变化并换算电流。它的重点是磁光效应，不是电流直接把光纤拉长。
- **光纤陀螺**：被测量是旋转角速度 `Ω`。Sagnac 环中顺、逆时针两束光在旋转时传播时间不同，产生与旋转有关的相位差。通过相位解调可得到角速度，光纤绕成多匝可以增大有效环路面积和相位响应。

三种应用都可以按同一模板理解：测什么 → 外界量改变了哪个光学参数 → 哪种干涉结构把变化读出来 → 采用什么解调和补偿得到结果。

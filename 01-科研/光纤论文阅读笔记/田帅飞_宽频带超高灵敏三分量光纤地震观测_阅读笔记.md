# 《宽频带超高灵敏三分量光纤地震观测关键技术研究》阅读笔记

## 一句话结论

论文围绕噪声、温度—应变解耦和光纤真实应变建模优化单轴加速度计，再集成为三分量地震计，开展实验室标定与台站对比。增加光纤长度不是唯一优化手段。

## 一、整篇论文的物理主线

```text
地震加速度
→ 质量块产生惯性力
→ 弹性盘片发生弯曲
→ 盘片上下表面的传感光纤被拉伸或压缩
→ 光纤长度和折射率发生变化
→ 光程发生变化
→ 两路光的干涉相位差发生变化
→ PGC系统解调相位
→ 根据标定灵敏度换算为加速度
```

但是，下面这些因素也会改变相位：

```text
光纤热噪声＋激光频率噪声＋环境温度＋光强及电路噪声
→ 产生额外相位变化
→ 可能被误认为真实地震振动
```

因此，论文的研究顺序是：

```text
确定不同频段的噪声来源
→ 分离温度与应变
→ 用有限元直接计算传感光纤应变
→ 优化灵敏度、工作带宽和测量分辨率
→ 制作三分量系统
→ 实验室及地震台站验证
```

## 二、重点概念澄清

### 1. 几何长度、折射率、光程和相位

#### 几何长度 (L)

光纤实际有多长。光纤被拉伸时，(L)增大；被压缩时，(L)减小。

#### 折射率 (n)

表示光在光纤材料中传播速度相对于真空减慢的程度。光纤受力或温度变化时，折射率也可能改变。

#### 光程 OPL

```text
光程 = 折射率 × 几何长度 = nL
```

光程不是单纯的物理长度，而是光在该介质中累积传播效果的等效距离。

#### 相位 φ

相位表示光波振荡到哪个位置。相位与光程的关系可写成：

```text
φ = 2πnL/λ
```

因此，应变造成的相位变化包含两部分：

```text
长度L改变造成的相位变化
＋折射率n改变造成的相位变化
```

**最容易混淆的地方**：仪器不是直接测量光纤长度，也不是直接测量质量块位移，而是测量两条光路的相位差，再换算为加速度。

### 2. 干涉与相位差

两路光合束干涉，将相位差信息转为探测光强变化。本文从光强信号中解调两路光的相位差，再换算为加速度；不是直接读取单束光的相位。

### 3. M-Z干涉仪

M-Z是Mach-Zehnder干涉仪。光被分成两个传感臂，在两条不同光路中传播后再次合束干涉。

本文利用两个传感臂分别连接盘片上下表面的光纤敏感环。盘片弯曲时，一臂光纤拉伸、另一臂压缩，使相位差变化增强。

**不要与OFDR混淆**：

- OFDR利用扫频、拍频和FFT获得光纤沿线位置分布；
- 本文是点式干涉测量，整段光纤共同形成一个传感器，不负责定位光纤上哪个位置发生振动。

### 4. 推挽结构

盘片上、下表面各有一个光纤环。盘片弯曲时：

```text
上表面光纤拉伸，产生正相位变化
下表面光纤压缩，产生反向相位变化
两臂作差后，两部分贡献相加
```

在两侧相位变化等幅反相、两臂响应可比时，差分相位变化约为单侧的2倍；一般情况应按两臂实际相位变化作差。

**最容易混淆的地方**：一侧拉伸、另一侧压缩看起来方向相反，但干涉仪测的是两臂相位之差，因此反向变化会在差分结果中相互增强，而不是抵消。

### 5. 灵敏度

加速度灵度定义为：

```text
S = 总相位变化 Δφ / 输入加速度 a
```

单位为rad/g。灵敏度越高，表示相同加速度能够产生越大的相位变化。

**灵敏度高不等于测量能力一定好**。因为灵敏度只看信号响应大小，没有考虑噪声。

### 6. 测量分辨率和自噪声

测量分辨率表示仪器能够从自身噪声中辨认出的最小加速度，数值越小越好：

```text
最小可测加速度 ≈ 相位噪声 / 加速度灵敏度
```

因此：

- 灵敏度增加有利于提高分辨率；
- 噪声增加会降低分辨率；
- 必须同时比较信号和噪声。

**最容易混淆的地方**：论文有时用“分辨率”指等效加速度自噪声，不是ADC的位数，也不是相位曲线上能看见的最小刻度。

### 7. 光纤热噪声与环境温漂

#### 光纤热噪声

光纤材料内部微观、随机的热力学涨落造成光程随机变化，表现为连续噪声谱。即使环境宏观温度看起来稳定，也仍然存在。

#### 环境温漂

环境温度缓慢升降，使光纤整体热胀冷缩、折射率变化，造成明显的缓慢相位漂移。

**二者区别**：

```text
光纤热噪声：微观、随机、形成噪声地板
环境温漂：宏观、缓慢、形成趋势性漂移
```

论文图2.12显示，约1 Hz～1 kHz主要受光纤热噪声限制；极低频处还会混入环境温度等慢扰动。

### 8. 激光频率噪声与光强噪声

#### 激光频率噪声

激光频率或波长发生随机波动。如果干涉仪两臂光程不完全相等，相同的频率变化会在两臂中积累出不同相位，最终变成相位差噪声。

```text
激光频率波动＋干涉臂长差
→ 相位差波动
```

减小臂长差和使用窄线宽、低频率噪声激光器，都能降低这种影响。

#### 光强噪声/RIN

激光输出功率随机波动。本文使用平衡差分探测抑制两路中共同存在的光强波动。

**二者不要混淆**：频率噪声改变光波的频率/波长，RIN改变光功率。

### 9. 功率谱密度与“主导噪声”

噪声谱描述不同频率上的噪声强度。横轴是频率，纵轴越高表示该频率处噪声越大。

判断主导噪声的方法：在同一频率上，哪一种理论噪声曲线最接近系统实测曲线，它就更可能是主要来源。

论文结论：

| 频段           | 主要判断                    |
| ------------ | ----------------------- |
| 约1 Hz～1 kHz  | 光纤热噪声占主导                |
| 约10 mHz～1 Hz | 总体主要受激光频率噪声影响           |
| 约1～10 mHz    | 理论拟合偏差增大，混入温漂等因素，不能简单归因 |

“主导”不等于“只有这一种噪声”，频段边界也会随光源、臂长差、光纤长度和环境变化。

### 10. 保偏光纤、快轴和慢轴

保偏光纤内部存在两个相互垂直的偏振本征轴，通常称为快轴和慢轴。两个轴的有效折射率不同，因此对温度和应变的相位响应也不同。

这里的两个轴是光纤内部的偏振方向，不是三分量地震计的上下、东西、南北方向。

### 11. 双同轴与双异轴干涉

“同轴/异轴”描述光在保偏光纤快慢轴之间怎样组合传播。

- 双同轴方案中，两路对温度和应变的响应比例可能比较接近，分离过程容易放大噪声；
- 双异轴方案改变两路偏振轴组合，使两路温度响应方向相反、应变响应方向接近，从而提高温度与应变的可分辨性。

正负号与光路组合和相位差方向定义有关。真正重要的不是“哪个轴天生为正或负”，而是两路响应比例不同。

### 12. 2×2响应矩阵与解耦

论文的两路观测可以展开成：

```text
第一路相位 = 第一路应变系数 × 应变 + 第一路温度系数 × 温度
第二路相位 = 第二路应变系数 × 应变 + 第二路温度系数 × 温度
```

论文标定值可直观写成：

```text
第一路相位 = 1.5648 × 应变 - 25.499 × 温度
第二路相位 = 1.5790 × 应变 + 24.600 × 温度
```

两路对应变都正向响应，对温度则一正一负。两条方程对应应变和温度两个未知量，因此可以通过矩阵求解。

近似理解：

- 两路相加：温度大致抵消，应变叠加；
- 两路相减：应变大致抵消，温度增强。

实际系数不完全相等，所以必须使用准确矩阵，不能只做简单加减。

> **待核实（本次内部审查）**：上式没有写出相位、应变、温度及四个系数的单位，也未明确是变化量还是含基线的绝对量。暂保留数值与符号，不用于直接代数计算。需核对原论文对应标定式、变量定义、单位和参考点；不能凭数值大小猜测应变单位。

### 13. 交叉敏感与横向串扰

#### 温度交叉敏感

仪器本来想测应变，但温度也改变了输出，这叫温度交叉敏感。

#### 横向串扰

单轴传感器本来只想测一个空间方向，但垂直方向的加速度也引起输出，这叫横向串扰。

两者不是同一概念：前者是“物理量之间串扰”，后者是“空间方向之间串扰”。

### 14. 轴向应变与径向应变

#### 轴向应变

沿光纤自身传播方向的拉伸或压缩。光纤绕成圆圈后，轴向大致就是沿圆周切线方向。

#### 径向应变

垂直于光纤传播方向的横向变形。它不一定直接增加光纤长度，但会通过光弹效应改变折射率，因此仍能改变相位。

论文有限元结果显示：同一侧光纤的轴向应变和径向应变符号相反，绝对值均随盘片半径增加而减小；径向/轴向应变绝对值之比约0.1722。

### 15. 光弹效应与泊松比

#### 光弹效应

材料受力产生应变后，内部折射率发生变化。它解释了为什么相位变化不仅来自光纤长度变化，也来自折射率变化。

#### 泊松比

材料沿一个方向被拉长时，垂直方向通常会缩短。泊松比描述纵向和横向变形之间的比例。

论文中的0.1722接近石英材料泊松比，说明传感光纤主要受到沿光纤方向的轴向应力，径向应变主要是相应的横向收缩结果。

### 16. 单匝、多匝和整根光纤积分

一根长光纤绕成很多圈后，从剖面看会出现很多小圆点。每个圆点是同一根连续光纤在不同匝位置上的横截面，并非许多互不相关的光纤。

盘片不同半径位置的应变不同，因此不能用一个点代表整根光纤。正确过程是：

```text
计算每一小段光纤的局部应变
→ 计算这一小段的相位变化
→ 沿一整匝积分
→ 对全部匝数和层数求和
→ 得到总相位变化
```

### 17. 有限元模型

有限元把连续、复杂结构划分为许多小单元，计算每个位置的位移、应力、应变和动态响应。

本文有限元模型直接包含：

```text
质量块＋弹性盘片＋粘接胶＋绕制胶＋涂覆层＋纤芯/包层
```

旧方法先计算盘片应变，再近似成光纤应变；本文直接计算光纤纤芯各位置的轴向和径向应变，因此更接近真实结构。

**有限元不是自动正确**。作者必须通过SensorA、SensorB实测结果验证模型。

### 18. 边界条件

边界条件描述结构哪些位置被固定、接触或受力。本文中盘片外边缘由壳体固定，内侧受到质量块的有限接触约束。

边界条件不准确时，即使材料参数正确，也可能得到错误的谐振频率和应变分布。

### 19. 杨氏模量、刚度和应变传递

#### 杨氏模量

反映材料抵抗弹性变形的能力。数值大通常表示材料更硬。

#### 结构刚度

不仅取决于材料杨氏模量，还与盘片厚度、几何尺寸和连接方式有关。

#### 胶的作用

胶不仅增加质量，还负责把盘片的变形传递给光纤：

- 胶太软时，胶层自身先发生较大剪切变形，光纤得到的应变减小；
- 胶适当变硬时，应变传递更充分；
- 粘接胶也不是越硬越好，论文结果显示灵敏度存在先增后减趋势。

### 20. 谐振频率与工作带宽

盘式传感结构可以近似看成质量—弹簧系统：

```text
谐振频率 f0 ∝ √(结构刚度k / 等效质量m)
```

- 盘片变厚或变硬：刚度增加，谐振频率提高，但灵敏度通常下降；
- 质量块增大：惯性作用增强、灵敏度提高，但谐振频率通常下降。

谐振频率决定工作带宽上限，但谐振频率不等于平坦工作带宽。论文样机谐振频率约348～354 Hz，最终给出的平坦工作频带约0.1～200 Hz。

### 21. 综合指标 (Sf_0^2)

作者用它同时观察灵敏度和谐振频率，避免只追求其中一项。

现阶段不需要推导。只需理解：某种改动如果只是让灵敏度提高、谐振频率大幅下降，未必真正改善综合性能。

### 22. 归一化灵敏度 (S_N=S/√L)

按本笔记的概述，作者用 $S_N=S/\sqrt{L}$ 比较灵敏度与光纤长度的权衡。增加光纤长度可能同时改变信号和噪声，不能只看原始灵敏度。

**AI条件推导（本次补充，非原文引述）**：若同一频率下，相位噪声幅度谱密度 $N_\phi=c\sqrt{L}$，且各方案的系数 $c$ 相同、主要受该噪声限制，则输入等效加速度噪声幅度谱密度为

$$N_a=\frac{N_\phi}{|S|}=\frac{c}{|S_N|}.$$

在这些条件下，$|S_N|$ 越大，输入等效噪声越小。若比较的是积分噪声或最小可测幅值，还须统一带宽和检测判据；其他噪声主导时，不能仅用 $S_N$ 排序。较短且布置合理的光纤可能更有利，但须比较实际噪声与灵敏度。

> **待核实**：本次未对照原论文确认上述长度标度、频段、$L$ 的单臂/总长定义与比较条件。公式是显式假设下的代数推导，不是原论文结论已获验证。

### 23. SensorA与SensorB

#### SensorA

作用是验证多匝有限元模型能否准确预测已经确定的结构：灵敏度偏差小于6%，谐振频率误差小于3%。

#### SensorB

作用是验证模型能否根据预定目标反向设计新传感器。目标为：

```text
灵敏度不低于15000 rad/g
谐振频率高于200 Hz
```

两只SensorB均达到目标。

### 24. 三分量地震计

一个单轴传感器只能测量一个方向。作者将三个单轴传感器尽量正交安装，分别测量：

- 上下方向；
- 东西方向；
- 南北方向。

三个方向不够正交时，一个方向的加速度会泄漏到另一个通道，增加横向串扰。

### 25. PGC解调

PGC是相位生成载波解调。相位调制器给干涉信号叠加已知的高频载波，再通过乘法、滤波和组合运算恢复外界造成的低频相位变化。

对本论文第一遍阅读，只需知道：

```text
输入：探测器输出的调制干涉电信号
处理：载波同步、混频、滤波和相位解算
输出：连续相位变化
```

不需要推导贝塞尔函数，也不需要学习FPGA代码。

### 26. NHNM与NLNM

- NHNM：全球高背景地震噪声模型；
- NLNM：全球低背景地震噪声模型。

传感器自噪声低于NHNM，表示它可以在典型高噪声环境中分辨部分真实地震背景，但不代表达到最安静地震台站的水平。低于NLNM才是更严格的目标。

### 27. 动态范围

动态范围描述最大可测加速度与最小可测加速度之间的跨度：

```text
DR = 20log10(最大可测加速度 / 最小可测加速度)
```

动态范围大表示既能测弱信号，也能承受较强信号。但论文的动态范围是由分别测试的最大量程和自噪声计算得到，不是一次实验中同时输入跨越全部范围的信号。

### 28. 直接标定与间接现场证据

- 实验室振动台测试属于受控标定，可以明确知道输入频率和加速度；
- 地震台站对比属于现场证据，说明仪器能够记录真实地震波，但输入信号并非人工精确控制。

论文的0.1～200 Hz主要有实验室标定支持；约0.01 Hz响应主要由现场与CTS-1E对比间接支持。因此，不能把“检测到0.01 Hz成分”完全等同于“0.01 Hz幅值和相位已经精确标定”。

## 三、各章核心内容

### 第二章：甚低频噪声

作者分别分析电路、散粒、量化、光强、激光频率和光纤热噪声，再与百米级干涉仪实测谱比较。主要结论是1 Hz～1 kHz以光纤热噪声为主，10 mHz～1 Hz总体以激光频率噪声为主，极低频还混入环境慢漂移。

关键证据：图2.12及2.6节。

### 第三章：温度—应变解耦

作者利用保偏光纤两个偏振轴的不同响应构造两条方程，通过2×2响应矩阵同时求出温度和应变。双异轴方案使两路温度响应方向相反，提高可分辨性。

关键结果：应变和温度最大测量误差分别为2.43 με和0.02°C，温度交叉敏感抑制超过30 dB。关键证据：图3.17、图3.18及3.5节。

### 第四章：有限元定量设计

作者直接建立包含传感光纤的有限元模型，发现光纤应变随半径增大而减小，并用样机证明有限元比旧等效方法更准确。随后研究胶、盘片、质量块和光纤环尺寸对灵敏度、谐振频率和分辨率的影响。

关键证据：图4.3～4.8、图4.9、图4.19、表4.5。

### 第五章：整机与验证

作者使用三个正交单轴传感器构成三分量系统，并集成窄线宽激光器、光电探测、ADC/DAC、FPGA/ARM、PGC解调和GPS/北斗授时。

主要指标：

| 指标 | 结果 |
|---|---|
| 工作频带 | 约0.1～200 Hz |
| 灵敏度 | 约8021～8730 rad/g |
| 谐振频率 | 约348～354 Hz |
| 横向串扰抑制 | 大于40 dB |
| 动态范围 | 153.22～180.40 dB |
| 自噪声 | 约0.05 Hz以上总体低于NHNM |

系统在宾县地震台记录了近震、远震和人工地震，典型事件与CTS-1E波形相关系数约0.94。关键证据：图5.10、图5.13、图5.14、图5.20～5.25。

## 五、论文的主要优点

1. 研究链条完整：从噪声、温度、结构模型一直做到三分量样机和台站观测。
2. 不只展示有限元图，而是使用SensorA、SensorB和不同外径样品进行定量验证。
3. 双异轴方法利用同一保偏光纤的两路响应分离温度和应变，物理逻辑清楚。
4. 同时测试灵敏度、带宽、自噪声、动态范围和横向串扰，没有只展示单一最佳指标。

## 六、论文的局限

1. 低于约10 mHz时，理论噪声与实测偏差较大，温度等环境因素没有完全分离。
2. 0.01 Hz低频响应主要由现场对比间接证明，缺少受控长周期标定。
3. 温度—应变解耦在最终260 m封装器件中的长期稳定性、热滞后和重新标定问题研究不足。
4. 统计表达较弱，缺少重复次数、标准差、置信区间和完整不确定度传播。
5. 有限元软件、网格收敛、胶层材料离散性及制造公差等复现细节不够完整。

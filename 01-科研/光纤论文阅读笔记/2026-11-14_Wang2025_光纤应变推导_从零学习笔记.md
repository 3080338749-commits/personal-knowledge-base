## 推导主线（一张图记住）
```
加速度 a → 惯性力 P = M·a → 圆盘弯曲，斜率 dω/dr ∝ P/D
→ 表面挪动 Δr = (t_d/2)·dω/dr → 盘面应变 ε = Δr / r          式(5)
→ 光纤在高度 t：力臂换成 t_d/2 + t，再乘胶传递效率 η_g        式(10)
```

## 第 0 步：应变是什么【AI】
- ε = ΔL / L（伸长量 ÷ 原长），**无单位**；拉长为正，压短为负。
- 1 με = 10⁻⁶。例：1 m 光纤伸长 1 μm → 1 με。
- 应变相同时，光纤越长总伸长越多 → 这就是论文绕 5 m 光纤的原因（总伸长大 → 相位变化大）。
- **伸长量有单位（μm），应变没有单位（με 只表示 10⁻⁶）。**

## 第 1 步：周向应变【AI】
- 一圈周长 L = 2πr；整圈从 r 挪到 r + Δr，伸长 ΔL = 2π·Δr。
- ε_θ = 2π·Δr / 2πr = **Δr / r**（一圈往外挪多少 ÷ 原半径）。
- 同样的 Δr，半径越小，应变越大。
- **相除前先统一单位。** 捷径：**Δr（μm）÷ r（mm）× 1000 = 应变（με）**。

## 第 2 步：中性面与表面挪动【AI】
- 板弯曲：外侧拉长、内侧压短，**中间那层长度不变 = 中性面**；离中性面越远，变形越大。
- 板倾斜小角度 θ 时，截面竖线跟着转，表面点离中性面 t_d/2，被带着横向挪动：**Δr ≈ (t_d/2)·θ**（弧长 = 半径 × 角度）。
- **Δr 是距离（相当于伸长量），Δr / r 才是应变**——两步是前后关系，不是一回事。

## 第 3 步：盘面应变公式 = 式(5)
- 【AI】ω(r) = 半径 r 处往下凹的深度（挠度）；dω/dr = 有多"陡"（斜率）；小角度时 **θ ≈ dω/dr**。
- 【AI】代入：ε = Δr / r = (t_d / 2r)·dω/dr。
- 【原文】式(5)：ε_sθ = −(t_d / 2r)·dω/dr（PDF p3 / 印刷 7480）。负号只表示拉/压方向（取决于坐标正方向），大小即上式。
- 【AI】外缘夹紧、内缘粘质量块 → 两处斜率 = 0 → 应变 = 0；中间某处最陡 → 应变最大（"中间高、两头低"）。峰值略偏内（因为还要 ÷ r），用表 II 参数估算约在 r ≈ 7.6 mm（AI 估算，非原文数据）。
- 【原文】FEA 中盘面周向应变沿径向呈 "downward-opening parabolic distribution"（Fig. 12a，PDF p8 / 7485）。

### 计算模板（固定三行）
```
① 半厚度：t_d / 2 = ___ μm
② 挪动量：Δr = 半厚度 × 斜率 = ___ μm
③ 应变：ε = Δr(μm) ÷ r(mm) × 1000 = ___ με
```
例：t_d = 0.4 mm，r = 4 mm，dω/dr = 0.0001 → ① 200 μm → ② 0.02 μm → ③ 0.02 ÷ 4 × 1000 = **5 με**。

## 第 4 步：斜率由什么决定
- 【原文】式(4) 惯性力 P = (M_m + M_de + M_ce)·a；式(2) 抗弯刚度 D = E_d·t_d³ / 12(1 − u_d²)（PDF p3 / 7480）。式(1)–(3) 为薄板弯曲方程（含 ln 项，未推导）。
- 【AI】两个规律：**斜率 ∝ P**（力越大弯越多），**斜率 ∝ 1/D**（板越硬弯越少）→ dω/dr ∝ M·a / (E·t_d³)。
- 【AI】**应变 ∝ 加速度**（线性）→ 这是 Fig. 17 灵敏度线性拟合成立的理论原因。
- 【AI】厚度的影响：ε = (t_d/2r)·dω/dr，力臂 ∝ t_d，斜率 ∝ 1/t_d³ → **ε ∝ 1/t_d²**。
  - 厚度翻倍：D ×8，斜率 ×1/8，力臂 ×2 → 应变 ×1/4。
  - 厚度 ×3（0.2 → 0.6 mm）：应变 ×1/9。对照 Fig. 7 读图（0.2 mm ≈ 20 rad/g，0.6 mm ≈ 3 rad/g，比值约 1/7），量级吻合；不完全相等是因为还没考虑线圈刚度（第 6 步）。
- 【AI】"t³"的原因（只记结论）：厚板截面更大，且材料离中性面更远。

## 第 5 步：光纤的力臂 = 式(10)
- 【AI】光纤叠在盘面上方高度 t 处，离中性面距离 = **t_d/2 + t**；把第 2、3 步的 t_d/2 换成它即可：ε = (t_d/2 + t)/r · dω/dr。
- 【原文】式(10)：ε_θ = −(η_g / r)·(t_d/2 + t)·dω/dr|_II；ε_r = −ε_θ·u_f·η_f（PDF p4 / 7481）。η_g 为盘面周向变形传给线圈的效率，|_II 表示线圈粘贴区（修正后）的斜率。
- 【AI】式(5) 与式(10) 只差一个力臂：表面 t_d/2，光纤 t_d/2 + t。
- 【AI】**力臂起点永远是中性面**：力臂 = 半厚度 + 这层光纤离盘面的高度 t；不是"光纤盘的厚度"。每一层光纤力臂不同，越往上越大（例：t_d = 0.4 mm，底层 t = 0.1 → 0.3 mm = 1.5 倍；顶层 t = 1.6 → 1.8 mm = 9 倍）。
- 【AI】第 0–4 步算的是**光秃秃圆盘自己表面**的应变（式 5 = 式 10 在 t = 0 时的特例），而且还假装线圈没有刚度。
- 【AI】**r 是这一圈光纤所在位置的半径**，不是圆盘外半径；每圈 r 不同，应变也不同。
- 【AI】应变 = η_g × 力臂 × 斜率_II ÷ r；先乘后除与"比值 = 力臂 ÷ r，再 × 斜率"结果相同（乘除可交换），比值法 mm ÷ mm 直接约掉单位。
- 【AI】周长法也一样：ε = 2π·Δr ÷ 2πr = Δr ÷ r（2π 约掉）；分子是 Δr 时分母必须是 r，不能除以周长。
- 【AI】力臂越大应变越大（例 r = 8 mm、斜率 0.0001：表面 2.5 με，顶层 22.5 με，正好 9 倍）。但不能无限叠高：线圈越高，力臂一次方增长，刚度近似三次方增长，叠到一定高度后变硬的影响盖过力臂 → 应变反而下降。

## 第 6 步：线圈加固修正 + 应变 → 相位
### 6a 线圈让圆盘变硬（式 7–9）
- 【原文】圆盘分三区（Fig. 5，PDF p4 / 7481）：边界约束区 I（外，靠夹紧处）、线圈粘贴区 II、加载区 III（内，粘质量块）。区 I、III 外载和结构不变，按无线圈模型算；只有区 II 需要修正。
- 【原文】式(7)：把线圈（光纤 + UV 胶）看成混合材料，按体积 V_g、V_f 得到等效模量 E_mix、泊松比 u_mix，等效抗弯刚度 D_mix = E_mix·t_g³ / 12(1 − u_mix²)（与圆盘式 2 同形）。
- 【AI】线圈厚度 ×2 → D_mix ×8；×3 → ×27；×4 → ×64（三次方）。
- 【原文】式(9) 两个条件：① 区 II 圆盘与线圈**斜率相等**；② 边界上的弯矩和剪力**按比例分给圆盘和线圈，总量不变**。式(8)：斜率由四种边界载荷叠加。
- 【AI】类比"两个人一起扛一袋米"：有线圈时区 II 斜率变小 → 老办法（忽略线圈）算出的应变**偏大**。修正后的斜率就是式(10) 里的 dω/dr|_II。
### 6b 应变 → 相位 → 灵敏度（式 11–14）
- 【AI】相位 = 光在光纤里一共"转"了多少（每走一个波长转 2π）；光纤被拉长，相位多转一点，仪器测的就是这一点。
- 【原文】式(11)：相位变化 = 长度变化（应变效应）+ 折射率变化（光弹效应，式 12，含 p11、p12）+ 直径变化（波导效应）。式(13) 为完整相位表达式，含 l_f·η_g·(t_d/2 + t)·dω/dr|_II。
- 【AI】石英光纤光弹效应约抵消 22%，常用近似：相位变化 ≈ β × 光纤长度 × 应变 × 0.78（0.78 为通用值，非原文数字）；波导效应可忽略。
- 【原文】式(14)：S = (g/a)·Δφ，单位 rad/g（PDF p5 / 7482）。
- 【AI】相位变化 ∝ 光纤长度 → 绕成多匝线圈是为了在十几 mm 的小圆盘上塞进 5 m 光纤，放大信号；5 m 也等于 G1–G2 光栅间距和干涉仪臂差。
- 【AI】提高灵敏度的途径：光纤更长、η_g 更高（胶薄且均匀 → 结论中"优化绕制工艺"）、质量块更重、圆盘更薄、线圈放在高应变区；但加重/变薄会降低谐振频率（硬快重慢），优化设计就是在两者间折中。

### 完整链条
```
加速度 a → P = M·a → 圆盘弯曲出现斜率（线圈让区 II 变硬，斜率变小）
→ 光纤应变 = η_g × 力臂 × 斜率_II ÷ r → 相位变化 ≈ β × l_f × ε × 0.78 → S（rad/g）
```

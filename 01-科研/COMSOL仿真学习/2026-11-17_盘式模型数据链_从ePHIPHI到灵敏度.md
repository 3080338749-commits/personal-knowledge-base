# 盘式模型数据链：从 ePHIPHI 到灵敏度

> 来源：Claude Code COMSOL 引导学习会话（2026-11-17 晚）。模型为教程小模型 za=3、ceng=4（上环 12 匝），粗化网格 7 389 个三角形。
> 标注约定：**【AI】** = Claude 讲解；**【原文】** = 教程；**【我】** = 我的回答原话；**【模型】** = 我自己 COMSOL 跑出的数。
> 讲解 PPT：`COMSOL参数图解_盘式加速度计.pptx` 第 11–18 页（数据部分 15–17 页）；三种应变见 [[01-科研/COMSOL仿真学习/2026-11-17_三种应变方向_ePHIPHI_eRR_eZZ]]。

## 一句话解释
【AI】加 1 g → COMSOL 算出每处应变 → 在每匝光纤圆心读 ePHIPHI → 换成每匝伸长量并求和 → 换成光相位 = 灵敏度（rad/g）。

## 整条链

![[图解_assets/流程11_全流程8步.png]]

```
输入（几何、材料、约束、附加质量 0.3 kg、重力 1 g）            ← 我填的
→ 稳态研究解出位移 → 应变 eRR / eZZ / ePHIPHI                 ← COMSOL 自动算
→ 数据① 截点：找到 12 匝光纤各自的圆心                         ← 告诉它“读哪里”
→ 数据② 2πr·ePHIPHI，点计算选“总和” → x1、x2                  ← 比例 → 长度，再相加
→ 数据③ ×0.001 × 2π·n/λ × 0.79 × 2 = S                        ← 长度 → 相位
```

## 第 0 步：最终要的数
- 【AI】干涉仪只认**光纤长度变化**（加折射率变化），看不见盘片弯了多少；不同半径/层的光纤伸长不同，所以必须到光纤位置读数。
- 【AI】灵敏度 S = 1 g 下的相位变化（rad/g）。模型加的正好是 1 g，且响应线性 → 算出的相位就是 S。
- 【原文】教程满尺寸（260 m 环）：S = 8013.8 rad/g，f0 = 282 Hz。

## ePHIPHI 从哪来

![[图解_assets/流程14_网格与两个研究.png]]

- 【AI】**不是我填的，是 COMSOL 的输出**。稳态求解受力平衡 → 每个网格点位移 u（径向）、w（轴向）→ 推出应变；轴对称下 ePHIPHI = u ÷ r。
- `solid.` = 来自“固体力学”物理场的变量；点计算里写它只是“点名读取”（类比 Excel 引用公式格子）。
- 可视化（可选练习）：结果 → 二维绘图组 → 表面 → 表达式 `solid.ePHIPHI` → 绘制；“替换表达式”按钮里 固体力学 → 应变 可找到全部应变变量。

## 数据①：截点 = 每匝光纤的“地址”

![[图解_assets/流程15_截点.png]]

- 一个点 = 一匝光纤（轴对称，截面一个圆心代表整圈）；点放纤芯圆心，因为光在纤芯里走。
- 光纤蜂窝错排、单双列差半根 → COMSOL 截点只能排整齐方格 → 拆成 截点 1（低列，对应“光纤”）和 截点 2（高半根列，对应“光纤1”），各 6 匝。
- range(起点, 步长, 终点)：
  - R 起点 ri + r3 = 15.0675 mm，步长 2·r3·√3 ≈ 0.234 mm（隔一列取，跳过另一组）；
  - Z 起点 c/2 + h2 + r3 = 0.7925 mm，步长 2·r3 = 0.135 mm（上下紧挨，一根直径）。
- 公式必须与画几何时的数一致，否则点落进胶里，读到的是胶的应变。
- 只取上环，下环对称反号，公式里 ×2。

## 数据②：2πr·ePHIPHI 求和

![[图解_assets/流程16_2πr乘ε.png]]

| 部分 | 意思 |
|---|---|
| r | 该点离轴距离，COMSOL 自动代入 |
| 2πr | 这一匝原长（周长，约 95 mm） |
| ePHIPHI | 沿光纤方向拉伸的比例（无单位） |
| 相乘 | 这一匝伸长量（mm）——**比例变长度**，长度才能相加 |
| 选“总和” | 6 匝加起来；“平均值”只是一匝 |

【模型】
| | 截点 1（6 匝） | 截点 2（6 匝） |
|---|---|---|
| 平均（每匝） | ≈ −0.00117 mm | −0.00125 mm |
| 总和 | x1 = −0.0070298 mm | x2 = −0.0075245 mm |

x1 + x2 = **−0.01455 mm**：上环缩短 14.6 µm（负 = 缩短）。验算 0.00125 × 6 ≈ 0.0075 ✓。平均应变 ≈ 0.01455 ÷ 1150 mm ≈ 12.7 微应变。

## 数据③：灵敏度公式

![[图解_assets/流程17_灵敏度公式.png]]

【原文】S = 2 × 0.79 × (x1 + x2) × 0.001 × 2π × 1.467 ÷ 1.55e-6

| 步 | 乘什么 | 意义 | 累计（本模型） |
|---|---|---|---|
| 0 | — | 上环总伸缩 | −0.01455 mm |
| 1 | × 0.001 | mm → m（λ 用米） | −1.455 × 10⁻⁵ m |
| 2 | × 2π × n ÷ λ | 光纤内波长 λ/n ≈ 1057 nm；缩短 14550 nm ≈ 13.8 个波长 × 2π | ≈ 86.5 rad |
| 3 | × 0.79 | 光弹效应抵消约 22% | ≈ 68.4 rad |
| 4 | × 2 | 推挽：上环缩短、下环伸长，干涉仪测两臂之差 | **≈ 137 rad/g** |

- 待问师兄：W65B-20 是 PM1310，若 λ = 1310 nm → 137 × 1550 ÷ 1310 ≈ 162 rad/g。
- 小模型 137 vs 教程 8013.8：光纤长 217 倍，灵敏度只大 58 倍。【AI 推测，待放大验证】外层光纤离盘面远、带动少；厚光纤环自身刚度撑住盘片。

## 质量、灵敏度与频率

![[图解_assets/流程18_小模型vs满尺寸.png]]

- 【AI】质量 ×2 → 惯性力 ×2 → 位移、ePHIPHI、x1+x2、S 都约 ×2（137 → ≈274 rad/g）。
- 【AI】频率 f ∝ 1/√m → ×0.71（198.2 → ≈140 Hz）；**S × f² ≈ 常数**，灵敏度和频带要折中（同 Wang 2025 “硬快重慢”）。
- 【模型】f1 = 198.2 Hz；手算光盘片 + 0.3 kg ≈ 215 Hz，量级一致。

## 易混淆
- 进公式的是**伸长量之和**（mm），不是应变；应变是比例不能直接相加。
- **伸长量有单位（mm/µm），应变无单位（微应变 = 10⁻⁶）**。伸长量 = 原长 × 应变。
- 点计算选“总和”不是“平均值”。
- 负号只表示缩短/伸长方向，S 取绝对值。

- 只写算式或数字，不写最终数值、单位与理由。

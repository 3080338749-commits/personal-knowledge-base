原有主题目录整体归入编号大类，目录内部结构不变。课程正文、概念卡片、复盘和状态源沿用硬件子库规则，不重建第二份进度数据。两个空白未命名笔记暂保留，避免删除未确认的工作入口。

推荐用 Obsidian 打开整个目录。GitHub 可浏览 Markdown 和图片，但不会运行 Dataview、Tasks 查询或 Obsidian 嵌入；仪表盘的动态区需在本地 Obsidian 查看。现有双链语法继续保留。

## 本地信息与公开版本

身份和联系方式集中于本地私密目录，该目录不进入公开发布副本。课题、学习进度、偏好、答题记录及电脑路径按本次约定保留。公开版只针对身份与联系方式做整理，不等于匿名化知识库。

发布副本不携带原 Git 历史、插件配置、配置备份或可再生成缓存。完整本地知识库继续保留这些资料。未统一授权第三方资料的再分发许可，也未给全库添加统一开源许可证。

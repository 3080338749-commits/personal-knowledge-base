# 元数据与掌握度规范

用于新增笔记；已有 YAML 不覆盖、不批量迁移。没有 domain 的旧笔记通过目录查询回退，保持可见。

| 字段 | 新笔记约定 |
|---|---|
| type | concept / paper / course / term / question / daily / review / weekly |
| domain | 科研 / 硬件 / 综合；历史值保留 |
| topic | 主题列表，如 [PGC, 相位解调] |
| status | inbox / learning / reading / completed / resolved；按类型适用 |
| mastery | null=待评估，0～5仅用于新科研体系；不能用0替代未知 |
| mastery_scheme | research-0-5；硬件仍从原JSON读取hardware-0-4 |
| source | 可追溯原笔记、文件路径、DOI/网址，多个来源可用列表 |
| created / updated | YYYY-MM-DD；updated为实际正文或状态变更日期 |
| next_review | 可选，YYYY-MM-DD；没有真实安排时省略 |
| related / evidence | 关联笔记列表、真实测验/复盘记录路径（可选） |

系统辅助笔记可使用 dashboard、plan、review-set、system、guide 等类型，不纳入独立学习知识点计数。status 是按笔记类型使用的建议值；历史值保留，不要求批量改成同一枚举。

## 科研新体系的0～5判定

| 值 | 证据标准 |
|---|---|
| null | 未测或证据不足 |
| 0 | 真实作答显示暂不会；不能仅因新建笔记判0 |
| 1 | 能识别术语，解释仍存在关键错误 |
| 2 | 能用自己的话说明基本概念与量纲/适用条件 |
| 3 | 无提示独立解释原理并完成基本分析 |
| 4 | 能在新问题中综合应用，说明局限与误差来源 |
| 5 | 经跨日复测仍可迁移应用，并可用来源核查纠错 |

3及以上为具备独立解释/应用证据；不是永久掌握保证。每次升降应带日期、题目、原回答和判定理由。历史A/B/C/D、提示后通过等保留原文，不机械换算数字。

硬件：保留原null/0～4和JSON事实源，3～4为原定义的确认掌握。统一首页不把两体系分数混成一个百分比。

## 旧论文状态兼容

`completed-first-pass`=首轮阅读完成，`completed-chapter-2`=第二章完成，均保留。reading/learning为正在阅读，inbox/to-read为待读；旧状态单列，不能自动宣称整篇精读完成。

## 学习事实和调度的归属

普通科研学习记录保留真实证据，next_review只记录人工安排；SR卡片调度由插件维护，不把其标记当个人掌握度。硬件复习只走原状态与维护工具。一次真实事件只统计一次。

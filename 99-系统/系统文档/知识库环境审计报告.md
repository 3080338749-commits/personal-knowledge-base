## 7. 关键风险与增量实施决定

1. **掌握度冲突**：硬件现有 null/0～4 与目标 0～5 不同。建议原硬件 level 完全保留；新增科研 metadata 使用 null/0～5，明确 mastery_scheme；展示分开统计，未知不填 0。不为了统一分数重写历史事实。
2. **双重调度**：原硬件 JSON 的复习计划与 SR 插件调度必须分开。卡片由插件负责调度，Codex 记录真实答题证据；不能把同次复习统计两遍，更不能直接从 SR 点击分数推测硬件等级。
3. **备份污染检索**：96 个备份 Markdown 会造成重复结果与失真统计。QMD collection ignore 和 Dataview 查询排除备份、模板、系统文档、缓存及派生索引等适用范围；原备份保留，不删除或移动。
4. **旧状态兼容**：论文的首读完成、章节完成与整篇完成区别保留；新增 domain 等字段不代表批准批量回填旧笔记。
5. **原生依赖**：QMD 2.8.3 依赖 better-sqlite3、sqlite-vec、node-llama-cpp；不能从 Node 满足版本推断必然运行。先隔离小集合，确认可用再索引真实库，失败时保留关键词能力，不替换系统 Node/Git。
6. **中文语义**：QMD 固定版官方说明支持 Qwen3-Embedding-0.6B 并建议用于 CJK；可作为中文库优先候选，实际优劣需本库查询验证，不能只凭模型名称认定效果。
7. **模型下载**：默认 embedding 约300 MB、reranker 约640 MB、query-expansion 约1.1 GB；改用 Qwen3 后 embedding 文件大小需下载前确认。下载、索引临时空间和运行内存都需预留；关键词阶段无需主动执行 embed/vsearch/query 触发模型下载。大型模型授权另行取得。
8. **规则范围**：新增 Vault 根 AGENTS.md 作为总入口；硬件子库现有 AGENTS.md 及唯一事实源优先适用，不运行全库重构。
9. **插件执行**：社区插件可执行代码并访问 Vault。需用户明确同意安装和启用；Git 默认仅本地，不设远程和自动 push。
10. **Codex 持续记忆边界**：日常使用应在主库打开 Codex 项目，或在提示词明确主库路径；本次聊天规则不能保证任意未来聊天自动定位该库。QMD MCP 注册后仍需 list 和实际工具调用验证，不能仅凭写入配置宣称接入。

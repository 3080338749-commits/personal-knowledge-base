本次范围：仅将身份和联系方式移入本地私密笔记，保留课题、学习偏好、进度、答题和电脑路径。主要目录、原资料与评分不重排。

## 推荐发布方式

使用本次生成的“知识库_GitHub发布副本”目录作为新仓库来源。它不含旧 `.git`，不携带历史提交的作者邮箱或迁移前身份文本；不要复制原知识库的 `.git` 进去。先检查该目录，再在 GitHub 创建空的公开仓库并从此目录初始化、提交与推送。当前尚未创建远程仓库或上传。

原知识库仍保留完整历史。`.gitignore` 只影响未跟踪文件，不会删除已跟踪配置，也不会清除旧提交。不要将原仓库直接推到公开远程并假定私密资料已经从历史消失。

## 发布副本排除内容

- 本地私密目录及标记为“（私密）”的笔记。

这是公开发布副本，不是本地完整备份。原库及库外整理前备份完整保留。

本地身份链接在发布副本中改成“身份与联系方式仅保存在本地私密笔记”，避免公开版出现必然失效的私密双链。其余正文不作匿名化，原有的科研主题、学习记录、个人偏好及本地路径仍可见。

原笔记中的截图、作者姓名、参考文献与第三方联系方式不是本人的身份资料，不按姓名或邮箱模式批量删除。图片未做 OCR 全面审查；不能据此承诺图中绝无个人信息。若准备以匿名账号发布，仍需扩大脱敏范围。

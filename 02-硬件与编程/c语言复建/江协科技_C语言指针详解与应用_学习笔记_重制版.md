## 1. 先理解内存、地址与小端

### 1.1 内存是什么

可以把内存想象成一排房间：

- 每个房间通常容纳 1 字节；
- 每个房间都有唯一编号，这个编号就是地址；
- 一个多字节对象会连续占用多个房间；
- 指针变量用于保存地址。

```c
int a = 10;
int *p = &a;
```

- `a`：一个 `int` 对象，里面存着数值 `10`；
- `&a`：对象 `a` 的地址；
- `p`：保存 `a` 地址的指针变量；
- `*p`：沿着 `p` 保存的地址找到 `a`，读取或修改它。

### 1.2 小端存储（重点）

假设：

```c
uint32_t value = 0x12345678;
```

这个数由 4 个字节组成：`12 34 56 78`。在小端机器中，低有效字节放在低地址：

| 地址 | 0x4000 | 0x4001 | 0x4002 | 0x4003 |
|---|---:|---:|---:|---:|
| 内容 | 0x78 | 0x56 | 0x34 | 0x12 |

记忆：

> 小端 = 数值的低位字节放在低地址。

注意，`0x12345678` 这个数本身没有被“倒过来”。变化的是它的各个字节在内存里的排列顺序。

可以在你的电脑上验证：

```c
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint32_t value = 0x12345678u;
    const unsigned char *bytes = (const unsigned char *)&value;

    for (size_t i = 0; i < sizeof value; ++i) {
        printf("bytes[%zu] = 0x%02X\n", i, bytes[i]);
    }
    return 0;
}
```

在常见的 x86/x64 Windows 电脑上通常会输出 `78 56 34 12`。

端序只有在观察或传输“多字节对象的字节表示”时才重要，例如：

- 串口和网络通信；
- 按字节保存整数或浮点数；
- 解析二进制文件；
- 读取硬件寄存器或协议数据。

## 2. 指针的定义与基本操作

### 2.1 定义指针

```c
int *p;
char *cp;
float *fp;
```

`int *p` 应读作：`p` 是一个指针，它指向 `int` 类型的对象。

指针所占字节数主要由目标平台决定，不由它指向的类型决定：

```c
printf("%zu\n", sizeof(int *));
printf("%zu\n", sizeof(char *));
```

在同一个普通平台上，这两个结果通常相同。64 位 Windows 程序中通常是 8 字节；32 位程序中通常是 4 字节。嵌入式平台则要以实际芯片、编译器和内存模型为准。

### 2.2 `&`：取地址

```c
int a = 10;
int *p = &a;
```

`&a` 得到 `a` 的地址，并用它初始化 `p`。

### 2.3 `*`：解引用

```c
printf("%d\n", *p);  // 读取a，输出10
*p = 20;              // 修改a
printf("%d\n", a);   // 输出20
```

声明中的 `*` 与表达式中的 `*` 作用不同：

- `int *p`：声明 `p` 是指针；
- `*p`：访问 `p` 指向的对象。

### 2.4 正确打印地址

```c
printf("%p\n", (void *)p);
```

地址应使用 `%p`，不要用 `%x`。`%x` 要求参数是 `unsigned int`，并不保证能容纳指针。

## 3. 指针类型为什么重要

指针类型至少告诉编译器两件事：

1. 解引用时应读取多少字节，并按什么类型解释；
2. 指针加减整数时，每一步跨过多少字节。

例如：

```c
int a[3] = {10, 20, 30};
int *p = a;

printf("%d\n", *p);       // 10
printf("%d\n", *(p + 1)); // 20
```

若一个 `int` 占 4 字节，`p + 1` 的地址通常比 `p` 大 4，而不是大 1。

重要限制：指针运算应在同一个数组对象内部进行，最多允许形成“尾后指针”，但尾后指针不能解引用。不要对单独变量随意执行 `p++` 后再解引用。

## 4. 数组与指针

### 4.1 `array[i]` 为什么能用在指针上

C 语言规定：

```c
array[i]
```

等价于：

```c
*(array + i)
```

所以函数参数写成 `const int *array` 时，完全可以在函数中写 `array[0]`、`array[i]`。下标运算不是数组变量专属，它本质上就是指针运算加解引用。

### 4.2 数组名经常转换为首元素指针

```c
int a[3] = {10, 20, 30};
int *p = a;       // 此处a转换为&a[0]
```

但不要记成“数组就是指针”。二者不是同一种对象：

- `a` 是含 3 个 `int` 的数组；
- `p` 是保存地址的指针变量；
- `sizeof a` 得到整个数组的字节数；
- `sizeof p` 得到指针变量自身的字节数；
- `p` 可以改为指向别处，数组名不能被赋值。

```c
printf("%zu\n", sizeof a); // 若int为4字节，结果为12
printf("%zu\n", sizeof p); // 64位程序中通常为8
```

### 4.3 数组传入函数后为什么还需要长度

```c
int FindMax(const int *array, size_t count);
```

数组作为函数实参时，通常只把首元素地址传进去。函数拿到一个指针，却无法仅凭这个指针知道数组有多少个元素，所以还必须传入 `count`。

## 5. 指针作为函数参数

### 5.1 C 语言始终是值传递

```c
void set_value(int *p)
{
    *p = 100;
}

int main(void)
{
    int value = 10;
    set_value(&value);
    printf("%d\n", value); // 100
}
```

调用时仍然是“值传递”，只是被复制的值恰好是地址。函数中的 `p` 是地址的副本，但 `*p` 对应调用者原来的对象。

### 5.2 只读输入参数：`const`

```c
int FindMax(const int *array, size_t count)
{
    int max = array[0];

    for (size_t i = 1; i < count; ++i) {
        if (array[i] > max) {
            max = array[i];
        }
    }
    return max;
}
```

`const int *array` 表示：不允许通过 `array` 修改元素。指针变量 `array` 自身仍可改变。

这个函数还应要求 `array != NULL` 且 `count > 0`，否则读取 `array[0]` 不合法。

### 5.3 输出参数：一次带回多个结果

```c
#include <stddef.h>

int find_max_and_count(const int *array, size_t length,
                       int *max_value, size_t *max_count)
{
    if (array == NULL || max_value == NULL ||
        max_count == NULL || length == 0) {
        return 0;
    }

    *max_value = array[0];
    *max_count = 1;

    for (size_t i = 1; i < length; ++i) {
        if (array[i] > *max_value) {
            *max_value = array[i];
            *max_count = 1;
        } else if (array[i] == *max_value) {
            ++(*max_count);
        }
    }
    return 1;
}
```

这里：

- `array` 是输入参数，只读；
- `max_value` 与 `max_count` 是输出参数；
- 返回值用于报告函数是否成功。

括号不能少：`++(*max_count)` 增加的是它指向的数值。

## 6. 从函数返回指针与“句柄”

可以返回生命周期足够长的对象地址，例如全局对象或静态对象：

```c
static int time_data[3] = {23, 59, 55};

const int *get_time(void)
{
    return time_data;
}
```

不能返回普通局部变量的地址：

```c
int *wrong(void)
{
    int value = 10;
    return &value; // 错误：函数结束后value的生命周期结束
}
```

这不是说 `value` 自动变成 0，而是该对象已经不存在。返回的地址成为悬空指针，解引用它属于未定义行为。

库中常见的 `FILE *`、设备对象指针等可以充当“句柄”：调用者不必知道对象内部细节，只把该指针传回相应接口。

## 7. 空指针、野指针与悬空指针

### 空指针

```c
int *p = NULL;
```

`NULL` 表示当前不指向有效对象。指针变量本身仍然占空间，只是它保存的是空指针值。空指针不能解引用。

### 野指针

```c
int *p;   // 未初始化，值不确定
*p = 10;  // 错误
```

### 悬空指针

指针曾经指向有效对象，但对象的生命周期已经结束或动态内存已经释放。

基本习惯：

- 定义指针时立即初始化；
- 暂时无目标就初始化为 `NULL`；
- 解引用前确认指针有效；
- 避免越界；
- 不返回普通局部变量的地址；
- 动态内存释放后及时将相应指针置为 `NULL`，同时注意其他别名仍可能悬空。

## 8. 二级指针

```c
int value = 10;
int *p = &value;
int **pp = &p;
```

- `p` 保存 `value` 的地址；
- `pp` 保存 `p` 的地址；
- `*pp` 得到 `p`；
- `**pp` 得到 `value`。

二级指针常用于：

- 函数需要修改调用者的指针；
- 动态创建对象并通过参数带回地址；
- 指针数组、二维动态结构和链表等场景。

```c
void redirect(int **target, int *new_target)
{
    *target = new_target;
}
```

## 9. 函数指针

```c
int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*operation)(int, int) = add;
    printf("%d\n", operation(1, 2));
    return 0;
}
```

`int (*operation)(int, int)` 表示：`operation` 是一个指针，指向“接收两个 `int` 并返回 `int`”的函数。

必须有括号：

- `int (*p)(int, int)`：函数指针；
- `int *p(int, int)`：声明一个返回 `int *` 的函数。

函数指针常用于回调函数、状态机、命令表、驱动接口和中断处理表。

## 10. 结构体指针

```c
typedef struct {
    const char *name;
    int age;
} Person;

Person person = {"Tom", 20};
Person *p = &person;

printf("%s %d\n", p->name, p->age);
```

```c
p->age
```

等价于：

```c
(*p).age
```

嵌入式驱动中经常使用“结构体 + 结构体指针”组织设备状态和操作接口。

## 11. 指针在嵌入式中的应用

### 11.1 访问指定硬件地址

概念示例：

```c
#include <stdint.h>

#define GPIO_OUT (*(volatile uint32_t *)0x40020014u)

void set_output(void)
{
    GPIO_OUT |= 1u;
}
```

- `0x40020014u`：硬件手册规定的地址；
- `(volatile uint32_t *)`：把该整数地址转换为指向寄存器的指针；
- `*`：访问该地址处的寄存器；
- `volatile`：告诉编译器该值可能被硬件等外部因素改变，每次都要真正读写。

这只是说明语法。实际地址、位含义和访问宽度必须以芯片参考手册为准；在普通 Windows 程序中随意访问这种地址会出错。

参考笔记中的 `code` 是部分 8051 编译器用于区分存储空间的扩展关键字，不是标准 C。STM32/GCC 中不能原样照搬。

### 11.2 把对象表示成字节

C 允许通过 `unsigned char *` 观察任意对象的字节表示：

```c
float number = 12.345f;
const unsigned char *bytes = (const unsigned char *)&number;

for (size_t i = 0; i < sizeof number; ++i) {
    printf("%02X ", bytes[i]);
}
```

但传输浮点数的原始字节时必须同时考虑：

- 两端浮点格式是否一致；
- 两端端序是否一致；
- 类型大小是否一致；
- 协议是否定义了字节顺序。

从字节缓冲区恢复对象，优先使用 `memcpy`：

```c
#include <string.h>

unsigned char data[sizeof(float)] = {0};
float number;
memcpy(&number, data, sizeof number);
```

不要简单写成 `float *fp = (float *)data;` 后解引用：缓冲区可能不满足 `float` 的对齐要求，还可能涉及有效类型和可移植性问题。

在正式通信协议中，更稳妥的做法通常是明确规定整数位宽、符号、缩放比例和字节序。例如温度 `12.345°C` 可按协议转换为整数 `12345` 后传输。

## 12. 动态内存：先认识，不必马上深挖

```c
#include <stdlib.h>

int *a = malloc(3 * sizeof *a);
if (a != NULL) {
    a[0] = 0x33;
    a[1] = 0x34;
    a[2] = 0x35;
    free(a);
    a = NULL;
}
```

必须掌握：

- 检查 `malloc` 是否返回 `NULL`；
- 使用 `sizeof *a`，不要把 `int` 大小硬编码成 4；
- 使用结束后 `free`；
- `free` 后不能继续访问原内存。

在资源受限或实时要求严格的嵌入式系统中，动态内存可能被限制或完全禁用，但指针本身仍然大量使用。

## 13. 参考笔记中需要特别修正的地方

1. **数组不是指针。** 数组表达式在多数场景会转换为首元素指针，但数组对象与指针变量不同。
2. **指针不是一定为 4 或 8 字节。** 大小取决于实现和目标平台，嵌入式平台尤其要实测。
3. **地址用 `%p` 打印。** 参数转换为 `void *`。
4. **`p++` 不能随意使用。** 指针运算必须遵守数组边界规则。
5. **`malloc(3 * 4)` 不可移植。** 应写 `malloc(3 * sizeof *a)`，并检查返回值、最终 `free`。
6. **原文件示例存在缓冲区越界。** `char s[10]; fgets(s, 15, f);` 最多可能写入 15 字节；应写 `fgets(s, sizeof s, f)`。
7. **不要写 `printf(s)`。** 若字符串包含 `%` 会被当成格式说明；应写 `printf("%s", s)` 或 `fputs(s, stdout)`。
8. **局部变量结束后不是“变成 0”。** 它的生命周期结束，指向它的指针成为悬空指针。
9. **直接把字节数组转换为 `float *` 并解引用不稳妥。** 用 `memcpy` 恢复对象更安全。
10. **8051 的 `code` 不是标准 C。** 它是特定编译器的存储空间扩展。

## 14. 一张表复习符号

| 写法 | 含义 |
|---|---|
| `int *p` | 声明一个指向 `int` 的指针变量 |
| `&a` | 取得 `a` 的地址 |
| `*p` | 访问 `p` 指向的对象 |
| `p + 1` | 移动到下一个同类型数组元素 |
| `p[i]` | 等价于 `*(p + i)` |
| `int **pp` | 指向 `int *` 的二级指针 |
| `s->member` | 通过结构体指针访问成员 |
| `int (*fp)(int)` | 指向相应函数的函数指针 |
| `NULL` | 空指针值，不能解引用 |
| `const int *p` | 不能通过 `p` 修改所指 `int` |
| `int *const p` | `p` 自身不能改指向 |
| `volatile uint32_t *p` | 所指对象可能被外部改变，常见于寄存器 |

## 17. 最短总结

> 指针变量保存地址，`&` 取得地址，`*` 沿地址访问对象；指针类型决定如何解释内存及移动步长；数组下标本质是指针运算；函数通过传递地址可以修改调用者对象或带回多个结果；嵌入式开发再把这些能力用于寄存器、缓冲区、通信协议和设备对象。

真正需要避免的不是指针，而是：无效地址、越界、对象生命周期结束、错误类型、错误长度和未定义的字节解释方式。

# 电感DCR与直流偏置电流核查

## 核心认知

DCR是绕组直流电阻，基本铜损可近似I_rms²DCR，另考虑温度/交流与磁芯损耗。电感的磁性偏置通常由直流电流决定；电流须核对饱和电感下降与温升等各自额定判据，不能照搬电容直流偏压措辞。

### ESR 与 DCR 的区别

- **DCR**：直流下测得的绕组铜电阻，固定值，万用表可测；估算直流铜损 P≈I²·DCR（如 2 A、50 mΩ → 0.2 W）。
- **ESR / R_s**：规定交流频率下把全部损耗等效成的串联电阻，随频率变化，须注明测试频率。电感 R_s ≈ DCR + 趋肤/邻近效应附加铜损 + 磁芯损耗；低频 ≈ DCR，高频远大于 DCR。
- 电容隔直，无 DCR 说法；直流下对应漏电流/绝缘电阻（**并联**大电阻）；电容 ESR 含电极、引线电阻与介质损耗（见 [[K-000014-电容ESR ESL与自谐振]]）。

### Isat 与 Irms 的区别

| | Isat 饱和电流 | Irms 温升电流 |
|---|---|---|
| 管什么 | 磁芯饱和 → 电感量骤降（常以下降 20%/30% 定义，依厂家） | 发热 → 温升达规定值（常见 40 ℃） |
| 拿什么比 | **峰值电流** I_peak = I_avg + ΔI/2 | **有效值电流** |
| 超了会怎样 | 电感↓→纹波↑→峰值↑ 恶性循环，快速失控 | 慢性过热、寿命下降 |

- 示例（自拟）：I_avg 2 A、ΔI 1.2 A → I_peak 2.6 A > Isat 2.5 A，已饱和；只看平均电流会误判。
- 电感偏置由**电流**决定（不要套用电容“直流偏压”的电压说法）。两项判据都要满足并各留裕量。

## 复习补充（2026-11-04，助手解释）

> 来源：[[SESSION-2026-11-04-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 峰峰值“上下各分一半”：类比气温围绕 20 ℃、最低到最高差 6 ℃，则最高 23 ℃、最低 17 ℃。
- 口诀：**饱和看峰值，发热看有效值**。
- 例：I_avg 3 A、ΔI 1 A → I_peak 3.5 A>Isat 3.3 A，会饱和；I_rms≈√(I_avg²+ΔI²/12)≈3.03 A<Irms 4 A，不过热。

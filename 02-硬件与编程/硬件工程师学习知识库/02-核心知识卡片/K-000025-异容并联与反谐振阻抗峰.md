# 异容并联与反谐振阻抗峰

## 核心认知

不同容值并联并非数量越多越好。某频段一支路感性、另一支路容性，并联导纳可能部分抵消，形成合成阻抗峰；看目标频带及含安装寄生的阻抗曲线，结合源负载和阻尼。

## 实际证据与限制

SESSION-2026-10-21-01：第3题首次否定绝对结论但明确不知原因；讲解后按0.1 Ω/2 Ω比较选A并给出阻抗小的理由正确，反谐振原因尚未独立说明。

## 复习补充（2026-11-03，助手解释）

> 来源：[[SESSION-2026-11-03-01-逾期薄弱项复习]] 中助手的讲解，属补充解释而非课程原文；典型数值以具体手册为准。不代表已掌握，掌握以学习状态 JSON 为准。

- 真实电容 = C + ESL + ESR 串联；低于 SRF 呈容性，高于 SRF 呈**感性**；容值越大 SRF 通常越低。
- 两电容 SRF **之间**：大电容已呈感性、小电容仍呈容性 → L 与 C 并联 → **并联谐振（反谐振）**，合成阻抗出现**尖峰**，可能比单颗电容更差。
- 对策：看含安装寄生的阻抗–频率曲线；容值间距不要过大或利用 ESR 阻尼；减小回路电感（见 [[专题-芯片去耦完整回路与PCB布局]]）。
- 无仪器也可验证：LTspice 中搭两组 C+ESL+ESR 并联做 AC 扫频即可看到尖峰。

## 复习补充（2026-11-04，助手解释）

> 来源：[[SESSION-2026-11-04-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 压低阻抗峰：① 增加阻尼（ESR 合适的电容或串小电阻）；② 缩小容值间距或用多颗同值；③ 减小 ESL/回路电感。
- 改完须复核阻抗曲线，改容值有时只是挪动尖峰。

## 复习补充（2026-11-09，助手解释）

> 来源：[[SESSION-2026-11-09-01-总览后到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 传球类比：在两个自谐振频率之间，大电容呈电感、小电容呈电容，并联成 LC 并联谐振（反谐振），能量在两者间来回交换，从外面看阻抗出现尖峰，**阻抗变大、去耦变差**。
- 对策要具体：补一颗**中间容值**（如 1 µF 与 10 nF 之间放 100 nF）；容值别差太多；低 ESL、贴近引脚；适当 ESR 起阻尼。

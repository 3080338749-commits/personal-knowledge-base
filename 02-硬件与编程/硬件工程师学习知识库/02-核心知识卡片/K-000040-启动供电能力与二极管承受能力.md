# 启动供电能力与二极管承受能力

## 核心认知

不能认定启动供电满足要求。电源及供电网络需在启动过程中提供负载和电容充电等所需电流，使电压及上电时序满足负载要求；二极管IFSM仅说明规定脉冲和温度条件下的承受能力，不证明上游供电充足。二极管能承受、电源能供应是两项分别核查的条件。题目已出现限流掉压及反复重启，需检查实际需求、限流/启动方式及供电路径。

## 复习补充（2026-11-18，助手解释）

> 来源：[[SESSION-2026-11-18-01-完整总览复习]] 中助手的讲解，属补充解释而非课程原文；示例数值与情境为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 按用户要求记录本例（情境为助手自拟的典型场景，与 10-26 测验同类，非实板实测）：电源经二极管给负载供电，二极管 IFSM 很大扛得住冲击，但上电时负载电压下掉、反复重启。
- 水源—水管—水龙头类比：电源是水源，二极管是水管（够粗不爆），负载是水龙头；水龙头一开水压就掉，问题在水源供不上，不在水管。
- 反复重启循环：上电 → 负载启动电流＋大电容充电电流超过电源最大输出或触发限流 → 电压被拉到复位阈值以下 → 负载复位、电流变小 → 电压回升、重新启动 → 再次被拉低。
- 核查：负载上电峰值电流（含电容充电）对比电源最大输出/限流阈值；同步测上电时电流与负载端电压波形；看线缆与二极管压降。例：电源最大 1 A、负载峰值 1.5 A → 供不上。
- 一句话：**二极管“扛得住”与电源“供得上”是两件事，分开核查。**

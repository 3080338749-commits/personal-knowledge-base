# FAULT消抖与持续限流热保护

## 核心认知

FAULT是故障报告端，不等于限流环路本身。TPS25221的过流FAULT报告带消抖（典型8 ms，规格6–12 ms），限流可能已在动作，而过流持续时间尚不足以触发报告，因此FAULT未拉低不能排除短时限流；这不是允许过流无限制通过8 ms。过温关断的FAULT置位不走同一过流消抖。持续短路时，器件压差与耗散P≈(VIN−VOUT)I增大，可能升温触发热关断；冷却后又重启，持续故障下可热循环，故电流可能间歇，而非永远维持恒流。恒流仅是可调节、尚未保护关断阶段的近似行为。

## 复习补充（2026-11-03，助手解释）

> 来源：[[SESSION-2026-11-03-01-逾期薄弱项复习]] 中助手的讲解，属补充解释而非课程原文；典型数值以具体手册为准。不代表已掌握，掌握以学习状态 JSON 为准。

- **限流 ≠ FAULT 报告**：限流环路立即动作；FAULT 只是报告，过流报告带**消抖（deglitch）**，TPS25221 典型 8 ms（6–12 ms），用于避免插拔浪涌误报。
- 因此 2 ms 短时过流下 FAULT 未拉低，不能排除已经限流。
- 持续短路：P≈(VIN−VOUT)·I 发热 → 热关断 → 冷却重启 → 再关断，输出电流间歇循环。

## 复习补充（2026-11-04，助手解释）

> 来源：[[SESSION-2026-11-04-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 保安类比：**限流**是立刻拦人；**FAULT** 是持续闹约 8 ms 才向上汇报。
- 例：过流 2 ms 不报告、20 ms（超过 12 ms 规格上限）会报告，两者都已限流。

## 复习补充（2026-11-12，助手解释）

> 来源：[[SESSION-2026-11-12-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- **芯片发热 = 芯片两端压差 × 电流**，不是输出电压 × 电流。例：5 V 输入、短路后输出 1 V、限流 0.6 A → (5−1)×0.6=2.4 W（1 V×0.6 A=0.6 W 是负载侧的功率）。

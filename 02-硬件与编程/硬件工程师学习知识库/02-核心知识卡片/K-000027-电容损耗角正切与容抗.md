# 电容损耗角正切与容抗

## 核心认知

串联RC近似下tanδ=ESR/|Xc|=2πfC·ESR，无单位；分母是容抗，不是电荷量或容量。核对测试频率、温度、交流电平及规定偏置条件；同等条件较小表示相对损耗较小。

## 复习补充（2026-11-03，助手解释）

> 来源：[[SESSION-2026-11-03-01-逾期薄弱项复习]] 中助手的讲解，属补充解释而非课程原文；典型数值以具体手册为准。不代表已掌握，掌握以学习状态 JSON 为准。

- 公式：**tanδ = ESR / |Xc| = 2πf·C·ESR**，|Xc|=1/(2πfC) 为**容抗**（不是容值、不是电荷量、也不是笼统的“阻抗”）；Ω/Ω 无量纲。
- 口诀：**“损耗电阻比容抗”**，越小越好。
- 与电感 Q 对比：

| | 电容 tanδ | 电感 Q |
|---|---|---|
| 公式 | 损耗电阻 / 容抗 | 感抗 / 损耗电阻 |
| 越好 | 越小 | 越大 |

## 复习补充（2026-11-04，助手解释）

> 来源：[[SESSION-2026-11-04-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 容抗 **|Xc|=1/(2πfC)**：随 f、C 增大而减小，全频段单调下降。
- 先降后升、在 SRF 处最低（≈ESR）的是**总阻抗 |Z|**，不是容抗；SRF 处容抗与感抗抵消，高于 SRF 感抗主导。
- 感抗 X_L=2πf·ESL，随频率一直上升。

# 电感品质因数与频率损耗电阻

## 核心认知

串联RL近似下Q=X_L/R_s=2πfL/R_s，无单位。分子是感抗，分母是该频率的等效损耗电阻，不是一律用DCR。比较测试频率、温度、交流电平及直流偏置电流等条件。

## 复习补充（2026-11-03，助手解释）

> 来源：[[SESSION-2026-11-03-01-逾期薄弱项复习]] 中助手的讲解，属补充解释而非课程原文；典型数值以具体手册为准。不代表已掌握，掌握以学习状态 JSON 为准。

- Q = X_L / R_s = 2πfL / R_s，无量纲；R_s 为该频率下等效串联损耗电阻（电感侧也常被称为“ESR”）。
- 高频时趋肤/邻近效应与磁芯损耗使 R_s > DCR，故不能全频用 DCR。
- 与电容 tanδ 对比见 [[K-000027-电容损耗角正切与容抗]]（tanδ 越小越好、Q 越大越好）。

## 复习补充（2026-11-09，助手解释）

> 来源：[[SESSION-2026-11-09-01-总览后到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- Q=X_L/Rs，分子是**感抗** X_L=2πfL，不是阻抗 |Z|（|Z| 已含 Rs）。例：10 µH、1 MHz → X_L≈62.8 Ω；Rs 0.5 Ω → Q≈126；Rs 1 Ω → Q≈62.8。
- 对照记：电容 tanδ=ESR/|Xc| 越小越好；电感 Q=X_L/Rs 越大越好。频率升高 Rs 也增大，Q 先升后降。

## 复习补充（2026-11-10，助手解释）

> 来源：[[SESSION-2026-11-10-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 计算技巧：MHz（10⁶）×µH（10⁻⁶）正好抵消，X_L=2π×f(MHz)×L(µH) 直接得 Ω。例：2 MHz、4.7 µH → 2π×2×4.7≈59 Ω；Rs 0.3 Ω → Q≈197。
- Rs 更大 → Q 变小。

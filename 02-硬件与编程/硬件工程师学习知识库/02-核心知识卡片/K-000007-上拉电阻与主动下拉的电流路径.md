# 上拉电阻与主动下拉的电流路径

## 正确认知

DONE主动拉低时，上拉电阻仍连接电源与低电平节点，电流经上拉电阻、DONE内部下拉通路回到地。不能因为NMOS沟道关断或栅极稳态电流很小，就认为上拉支路也无电流。

教学变式：3.3 V经4.7 kΩ上拉，DONE理想低电平0 V，上拉电流约0.702 mA。NMOS源极也为0 V时VGS=0，LED主回路可同时处于关断状态。真实电路须按VOL、IOL和允许灌电流校验，而非无条件假设0 V。

- DONE 为**开漏输出**：主动拉低时内部下拉 NMOS 导通，完整回路为 3.3 V → 4.7 kΩ → DONE 引脚 → 内部 NMOS → GND，约 0.70 mA。
- 实际低电平是手册的 **VOL** 而非 0 V，须按 VOL/IOL 校验引脚灌电流能力。

## 复习补充（2026-11-04，助手解释）

> 来源：[[SESSION-2026-11-04-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 高阻态：NMOS 关断后无回路，电流≈0、电阻压降≈0，引脚≈上拉电压，这就是开漏靠上拉输出高电平的原理。
- 计算拉低电流用电阻两端**压差**：10 kΩ、3.3 V、VOL 0.4 V → 2.9 V/10 kΩ=0.29 mA。

## 复习补充（2026-11-06，助手解释）

> 来源：[[SESSION-2026-11-06-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- **VOL = 输出低电平电压（Voltage Output Low）**：引脚拉低时的实际电压。NMOS 导通有导通电阻，灌电流流过产生压降，所以不是 0 V（例：3 mA×100 Ω=0.3 V）。
- 手册按某个 IOL 条件给 VOL 最大值；灌电流越大，VOL 越高。
- 对端要认作低电平，须 VOL＜接收端 VIL。同类参数：VOH/VOL 输出高/低电平，VIH/VIL 输入高/低门限。

## 复习补充（2026-11-09，助手解释）

> 来源：[[SESSION-2026-11-09-01-总览后到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 门槛线类比：VIL 是对方芯片算作“低”的线，VOL 是引脚拉低时实际站的位置；**VOL 在 VIL 下面才算低**。例：VOL 0.4 V＜VIL 0.8 V 能认，余量 0.4 V；VOL 0.9 V＞0.8 V 不能认。
- 灌电流增大 → NMOS 导通电阻压降增大 → VOL 抬高，可能超手册保证值并逼近 VIL 而误判；所以上拉电阻不能太小。

## 复习补充（2026-11-10，助手解释）

> 来源：[[SESSION-2026-11-10-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 拆字母记 VOL：**V**oltage 电压、**O**utput 输出、**L**ow 低 → 输出为低时引脚上的实际电压。
- **VOL 本身就是 NMOS 导通电阻上的压降**（引脚经 NMOS 到地），所以灌电流越大 → 压降越大 → **VOL 越高**。
- 例：3.3 V 经 820 Ω 上拉，VOL 0.4 V → (3.3−0.4)/820≈3.5 mA＞IOL 3 mA，VOL 不再保证≤0.4 V，离 VIL 0.6 V 余量变小；上拉至少 2.9 V/3 mA≈967 Ω，可选 1 kΩ。

## 复习补充（2026-11-12，助手解释）

> 来源：[[SESSION-2026-11-12-01-到期复习]] 中助手的讲解，属补充解释而非课程原文；示例数值为自拟。不代表已掌握，掌握以学习状态 JSON 为准。

- 区分 O 与 I：**VOL**（Output）是输出端自己拉低时引脚的实际电压，“我实际站在哪”；**VIL**（Input）是接收端的门槛，“低于这条线才算低”。“低于它就认作低”说的是 VIL，不是 VOL。
- 上拉电阻变小时 VOL 变高，两种看法一致：分压看，上拉分得少、引脚留得多；电流看，电流大 → NMOS 压降大。

# 日常快捷指令

按常用频率排列。复制代码框内内容到Codex；有【占位内容】时先替换。首次先读 [[知识库使用与维护指南]]。

## 1. 每天开始

```text
继续硬件课程学习。按AGENTS.md恢复状态，按今天北京时间刷新到期复习，汇报未完成任务、下一节与资料页码。
```

## 2. 学完一节

```text
今天学完了。先确认本次实际学习范围，再一次一道题测验，通常5–8题；逐题保存答案，结束后更新笔记、错题、复习和仪表盘。
```

## 3. 今日复习

```text
开始今日复习。按今天日期选择到期或逾期知识，优先薄弱点和错题，一次一道题，保存结果并安排下次复习。
```

## 4. 整理笔记

```text
整理本节笔记。更新现有章节ID对应笔记，结合讲义页码、我的问题与实际回答，保留个人补充，不生成未学章节。
```

## 5. 记录疑问

```text
记录当前疑难问题：【问题原文】。关联当前章节、来源页和我的理解；相同问题追加，保留待解决状态。
```

## 6. 恢复中断

```text
恢复上一次未完成的学习任务。读取已保存测验题目和回答，从下一道未答题继续，不重复出已答题或虚构结果。
```

## 7. 检查掌握

```text
检查我的知识掌握情况。先读已学知识和实际测验证据，说明哪些仍待评估，再逐题回忆检验，更新有证据的等级。
```

## 8. 刷新仪表盘

```text
更新学习仪表盘。读取唯一学习状态，按今天北京时间重新计算，不修改实际学习事实；汇报状态版本、日期及校验结果。
```

## 9. 每周总结

```text
生成本周学习总结。以北京时间周一至今天的实际记录为范围，说明课程进度、掌握、错题及复习，保存总结并给下周建议。
```

## 10. 阶段测验

```text
进行阶段综合测验。只覆盖真实已学内容，先明确范围，一次一道题，保存实际回答、引导和未完成状态。
```

## 11. 知识库健康

```text
检查知识库是否存在数据问题。验证ID、状态、日期、重复笔记、失效内部链接及派生版本；先报告差异，不无故重写全部笔记。
```

## 12. 新增资料

```text
重新扫描新增课程资料。与现有清单和哈希比较，只处理新增或改变文件；失效解析标记待重读，保留旧记录，不改动原资料。
```

## 13. 错题专项

```text
开始错题复习。优先未解决与反复答错的已学知识，先问再引导，保留首次作答和提示后的表现。
```

## 14. 纠正笔记

```text
核对并纠正【笔记名称】中的【原句】。检查原资料，先备份，保留我的原文与修订说明，同步实际受影响的链接和知识状态。
```

## 15. 中途保存

```text
保存本会话已经确认的学习内容和实际答案，保留未完成测验、学习页段与下一步任务，刷新仪表盘并核验文件。
```

## 学习与逐题考核
“今天学完了”“今天学习完成了”“这一节学完了”自动确认范围并开始通常 5–8 题，一次一道，概念/原理/应用兼顾。错误先引导；保存首次和提示后作答，不把提示后正确当首次独立正确。每答一题增量保存，允许中断继续，不判未答题。最终将全文证据存入 `01-课程知识库/01-基础知识培训/测验与复习记录/`，quiz 保留最近/当前测验。
课程状态与知识等级独立；用户确认内容学完且完成测验，或明确跳过才完成单元。掌握 null 待评估、0 未学、1 理解不足、2 解释概念、3 独立分析、4 综合应用；3–4 计确认掌握。无实际作答不能推测升级。
实际错误追加错题事件，关联章节/知识/题干/原回答/纠正/来源。疑问解决保留历史。资料质量问题不算用户错题。

## 复习
“开始今日复习”按当前日期筛到期/逾期，优先薄弱与真实错题，一次一题主动回忆。初始目标为实际学习后 1/3/7/14/30 天；依据维护规则重排，实际作答后才更新等级与下一日期，追加复习事件。没有学习数据不建虚假任务。Codex 关闭后不实时运行，不声称后台检查或提醒。

1. 读取相关现有文件、状态 revision 和 SHA256；备份人工笔记及配置。检查其他会话和事务残留。
2. 最小增量更新章节笔记，保留“我的补充”和用户原文。冲突先分析，禁止盲目覆盖。笔记先保存再被状态引用。
3. 构建候选学习状态 JSON，revision 加 1，追加有稳定事件 ID 的实际答题/日志/错题/复习，保留未完成任务与下一题，去重防重放。
4. 用 `09-系统配置/维护工具.py commit --input 候选文件 --expected-sha 原状态哈希` 提交；哈希冲突时重读合并。

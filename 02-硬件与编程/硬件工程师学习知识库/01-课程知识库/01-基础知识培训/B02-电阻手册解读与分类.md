## 第一部分：先学会读手册（13–29页）

### 1. 型号、封装、功率和标码分开看（14–20页）

课件先列Vishay、YAGEO、KOA等厂家，再问0805功率、5.1 kΩ标码、0402尺寸，随后用手册解释。厂家名单用于定位资料，不是性能排名。

| 看见的标识 | 它表示什么 | 不能直接推出什么 |
|---|---|---|
| 0402/0603/0805 | 本课通常为英制封装代号 | 不等于厚膜/薄膜，也不唯一确定功率 |
| 512、1002、88A | 器件本体阻值编码，规则须确认 | 不能当封装或完整订货型号 |
| RC、RT等系列及完整型号 | 厂家技术/规格/包装等信息组合 | 不同厂家的同样字母不保证含义相同 |
| F/J等容差字母 | 课件YAGEO示例中F=±1%、J=±5% | 不能脱离具体系列移用到所有元件 |

额定功率要看具体系列。课件第28页同一尺寸列不同功率选项，因此“0805常见1/8 W”只能作部分型号经验，不能当唯一规格。只有阻值和封装相同，仍不足以判断能否替换。

### 2. 结构和尺寸怎么读（21–23页）

课件厚膜示意包括陶瓷基板、电阻层、电极、保护层和端头。结构帮助理解温度与可靠性；不要求背完整制造流程。

本课英制0402常见标称约1.0×0.5 mm，0603约1.6×0.8 mm，0805约2.0×1.25 mm。**这是外形量级，不是焊盘尺寸**；公差、厚度、端头和推荐焊盘查具体尺寸图。公制0402可能指另一尺寸体系，不与英制混用。

### 3. 表面阻值标码与标准值（24–26页）

第24页列三位、四位、EIA-96和无标码，第25页列标准阻值。先确认规则再解码：普通三位码前两位有效数字、末位为10的指数，四位码前三位有效数字、末位为指数，结果以Ω计。

课件5.1 kΩ对应**512=51×10² Ω**。你问过的**522=52×10² Ω=5.2 kΩ**也按这个规则；二者不要混淆。带R的小数、零欧和EIA-96完整说明保留在下方，不再散落文末。

以下为此前按厂家核实的补充。这里讲的是器件本体表面标码，不是PCB位号（R15等）、封装代号（0603等）或完整订货型号，不能相互混读。

### 普通纯数字码

先确认该系列采用普通数字标码，再按以下规则计算，结果以Ω为单位：

| 类型 | 规则 | 示例（按规则推算） |
|---|---|---|
| 三位码abc | 前两位ab为有效数字，末位c为10的指数：ab×10^c Ω | **522＝52×10² Ω＝5200 Ω＝5.2 kΩ** |
| 三位码 | 同上，末位0表示乘1，不是零欧 | 100＝10 Ω；101＝100 Ω；102＝1 kΩ；103＝10 kΩ；472＝4.7 kΩ |
| 四位码abcd | 前三位abc为有效数字，末位d为10的指数：abc×10^d Ω | 1002＝100×10² Ω＝10 kΩ；3160＝316 Ω；4992＝49.9 kΩ |

“522”的结果是普通三位规则下的数学解码，不表示该厂家某个具体系列一定供应5.2 kΩ；供应值与具体器件身份仍需订货型号确认。不能把522直接读成522 Ω。三位/四位码与容差的对应取决于系列，不能看到三位就断定±5%，或四位就断定±1%。

### R、小阻值、零欧与EIA-96

- **R表示小数点**：例如6R8＝6.8 Ω、R22＝0.22 Ω、31R6＝31.6 Ω、R020＝0.020 Ω＝20 mΩ。低阻采样电阻还可能有专用标码或横线，必须看该系列表格，不能套普通末位指数法。
- **零欧跳线**：YAGEO标码文件有0及000等示例。零欧是标称跳线，不代表物理电阻严格为零；电流与功耗限制仍需查手册。注意普通数字码100是10 Ω，不是零欧。
- **EIA-96是两位数字加一位倍率字母**：前两位要查数值表，不直接当有效数字。例如该表88对应806，A对应×1，因此88A＝806 Ω；01对应100，C对应×100，因此01C＝10 kΩ。X、Y、A、B、C、D、E、F在该表依次对应0.1、0.01、1、10、100、1000、10000、100000。具体系列是否采用该法仍需核对，不把所有末尾字母都当倍率。
- 小封装或特殊系列可能**没有表面标码**，不表示零欧或损坏。YAGEO AR0402明确无标记。

### 实际识读顺序

1. 先确认器件确是电阻、标码方向和字符；区分数字0与字母、横线等标记。
2. 查对应系列手册的MARKING，确定普通三/四位、R小数或EIA-96等规则，再解码。
3. 与BOM、卷盘标签及完整型号交叉核对。标码通常不够确定功率、最高工作电压、TCR或全部容差信息。
4. 必要时断电并放电后测量；在板测量受其他并联路径影响，不能直接据读数判该电阻阻值，必要时断开一端复核。

### 4. 规格表与降额：电阻不是只有“多少欧”（27–29页）

| 项目 | 实际检查 |
|---|---|
| 标称阻值与容差 | 是否覆盖目标范围；10 kΩ±1%初始范围9.9～10.1 kΩ |
| 额定功率与降额曲线 | 在规定环境/安装下允许耗散多少功率，高温是否需降低 |
| 最大工作电压 | 持续电压限制，不能当作短时过载电压 |
| TCR | 温区、正负与ppm/℃；初始精度和温漂是不同维度 |
| 封装/尺寸/端头 | 能否安装、焊接和散热 |

恒定直流、阻值近似不变时：

$$
I=\frac{V}{R},\qquad P=VI=I^2R=\frac{V^2}{R}.
$$

V用V、R用Ω、I用A，P得到W。实际功率要低于该工况允许功率，两端电压同时低于最大工作电压；不能只过其中一项。教学反例：1 MΩ、允许0.1 W且最大工作100 V的电阻，承受200 V时仅0.04 W，功率未超但电压已超。

## 第二部分：电阻怎样分类、各有什么取舍（31–43页）

![[01-课程知识库/01-基础知识培训/附件/B02-课件顺序-P033-电阻分类实物.png]]

第32页同时按材料、用途、敏感功能分类；第33页展示实物。这些是不同维度，不能把“功率电阻”“厚膜”“贴片0805”当成互斥的三类。

| 类别 | 结构/课堂特点 | 常见优势与用途 | 取舍与限定 |
|---|---|---|---|
| 碳膜（35页） | 陶瓷基体上形成碳膜并修调 | 部分常规引线应用成本低 | 精度、噪声、温漂按系列；高压/脉冲能力不能只凭材料名称判断 |
| 厚膜贴片/金属玻璃釉（36页） | 电阻材料印刷、烧结于基板 | 通用贴片、成本与供货方便 | 与薄膜相比往往更易取得低成本方案；精密厚膜也存在，不能一概说精度差 |
| 薄膜贴片（37–39页） | 蒸发/溅射等沉积电阻膜再修调 | 容易获得较小容差、低TCR，用于精密分压和测量 | 成本、脉冲/过载能力、长期漂移看具体型号，不保证所有指标都优于厚膜 |
| 金属膜引线（40–42页） | 陶瓷棒等基体上形成金属膜 | 低噪声、稳定性较好的常规/精密应用 | 不是与“薄膜工艺”完全互斥的抽象分类；课件此处比较的是具体产品形式 |
| 线绕/方形功率（33页） | 电阻丝绕绝缘骨架 | 功率耗散、电流检测等，按系列 | 寄生电感及高频行为要核查，不能仅因耐功率就用于任意高频电路 |
| 热敏、光敏、压敏（32–33页） | 阻值随温度、光照或电压等变化 | 感测、启动抑流或过压保护等特定用途 | 非线性/敏感器件不能直接当普通固定电阻替代 |

碳质、合成膜及其他敏感类型在课件总览出现，未逐一展开；不补造对应已学课时。课件“金属玻璃铀”按技术术语理解为玻璃釉，不是强调含铀材料。

### 精度、温漂、长期稳定性要分开（39–43页）

0.1%表示初始允差，不表示全温全寿命都保持0.1%。TCR的线性近似为：

$$
\Delta R\approx R_0\alpha\Delta T,\qquad
\alpha=\mathrm{TCR}[\mathrm{ppm}/{}^\circ\mathrm C]\times10^{-6}.
$$

R0为参考温度下阻值（Ω），ΔT为温差（℃），ΔR为变化量（Ω）。正TCR升温增阻，负TCR升温减阻；若只给±范围不能确定实际方向。

**教学比较：** 都为10 kΩ，温差50 ℃，100 ppm/℃对应约50 Ω温漂，25 ppm/℃约12.5 Ω；初始±0.1%为±10 Ω，初始±1%为±100 Ω。前者初始更准不等于温漂更小。老化、湿度、焊接和自热引起的变化另行考虑，不用初始允差代替全部误差预算。

## 第三部分：按照电路需求选型（45–49页）

1. 从功能算目标阻值，再选可采购标准值；不是任何场景都取最接近值，保护阈值等还要看上下边界。
2. 算实际电流、功耗、电压，结合温度降额和必要裕量选系列/封装。
3. 校验阻值容差、TCR与必要的长期稳定性；有启动冲击/脉冲时另查承受能力。
4. 核对封装、库存、成本及可替代性。上拉/下拉也要算有效逻辑电平和电流，不能因为不敏感就任意选库存值。

第49页是工作表图标，不假装已经展开了其未显示的计算表。更完整的厂家参数英文对照保留在文末，主线不重复列三遍。

### 厂家参数对照与补充查阅

来源是本聊天中阶段测验之后的“阅读一个电阻元器件手册应重点关注什么”问答。本段只保存助手解释，不表示用户已学完或已掌握，不新增掌握等级、复习事件或课程完成记录。

| 参数 | 常见英文 | 检查内容 |
| --- | --- | --- |
| 标称阻值及范围 | Resistance / Resistance Range | 目标阻值、单位与该系列覆盖范围 |
| 阻值允差 | Resistance Tolerance | 规定参考条件下初始阻值允许偏差 |
| 温度系数 | TCR | ppm/℃或ppm/K，温区、绝对值与规格范围 |
| 额定功率 | Rated Power / Rated Dissipation | 持续耗散功率及其规定环境、安装条件 |
| 功率降额曲线 | Derating Curve | 实际温度下允许功率；最高工作温度不等于仍可满额使用 |
| 最大工作电压 | Maximum Working / Operating Voltage | 允许持续施加的电压，不能把短时过载电压当持续值 |
| 工作温度范围 | Operating Temperature Range | 是否覆盖实际环境，并结合自热与降额理解 |
| 封装尺寸 | Dimensions / Package | 长宽高、公差、推荐焊盘；核对英制/公制 |

### 两个同时满足的条件

恒定直流、阻值近似不变时，实际功率P=U²/R须不超过实际条件下允许功率；两端电压还须不超过最大工作电压。功率符合不保证电压符合。

助手自拟反例：1 MΩ、允许功率0.1 W、最大工作电压100 V，施加200 V时功率为0.04 W，虽然功率未超标，但电压超标，不能持续使用。

### 按用途加看的项目

- 初始允差、温漂、长期漂移是不同指标；±0.1%不表示所有温度和使用时间下总误差都不超过±0.1%。
- 有开机冲击或脉冲时看脉冲承受曲线；精密测量时进一步看长期稳定性、噪声等适用指标。
- 规格表中的脚注、阻值范围、运行模式和测试条件必须一起看，不能任意拼接同系列不同条件下的最好指标。

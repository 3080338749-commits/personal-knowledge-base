# 状态数据规范

## 三个唯一事实源

| 文件 | 管理对象 |
|---|---|
| 学习状态.json | 学习、测验、知识掌握、个人疑难、错题、复习、日志及当前任务 |
| 课程目录.json | 不随每次学习改变的稳定章节ID、原文标题、来源、页段及覆盖范围 |
| 资料清单.json | 212个源文件、SHA256、大小、修改时间、文本缓存、提取与审阅状态、压缩包目录 |

编码UTF-8，日期YYYY-MM-DD，事实时间ISO8601带时区偏移：2026-11-03 起为+09:00，此前记录的+08:00保留不改。null为未知，不用0假充未知。schema_version=1；revision只在学习事实提交时+1，纯刷新保持版本。时区Asia/Tokyo（2026-11-03 起；此前Asia/Shanghai）。

## 学习状态字段

- current_unit_id/next_unit_id：当前/下一单元，允许null；当前初始null、下一B01。
- units：章节ID到status、completed_at、evidence、note的映射；note是相对于知识库根目录的Markdown路径。
- knowledge：每项id、title、unit_id、note、learned_at、level、evidence、due、review_stage。无实际学习不自动产生记录。
- questions：id、date、unit_id、question、context、status、resolution；解决后保留历史。
- errors：每次真实错误的独立id、date、knowledge_id、question、user_answer、correction、hints、status；同知识多次错误分事件。
- sessions：id、date、unit_id、content、source_pages、quiz_summary、issues、quiz_answers；保存实际题干、首次回答、追问回答、判定与证据。
- reviews：id、date、knowledge_id、question、user_answer、hints、result、old_level、new_level、next_due；不覆盖旧结果。
- quiz：null或{id,unit_id,status,scope,planned_questions,answers,next_question_index,summary}；answers每项含question、user_answer、hints、follow_up_answers、assessment、knowledge_ids；下一题基于实际未答范围而非假分数。
- tasks：id、title、status、unit_id；未完成任务跨会话保留。

稳定ID：B01–B18基础主题、S01–S12交换机主题、I01–I40原课时；K-000001知识、Q-000001疑问、ERR-000001错题；SESSION-日期-序号、REVIEW-日期-序号。ID永不复用，提交前查全库和状态；合并重复时保留旧ID映射。

资料身份SRC采用首次相对路径SHA256前12位。初次命名后固定；以后改名用完整内容哈希识别同一文件。重复原资料都保留索引，可共享缓存，不删除原件。提取文本和已读正文分字段。

## 维护工具

`09-系统配置/维护工具.py`仅用Python3标准库。由Codex定位当前可用运行时，不要求用户每天配置。入口：

```text
python 09-系统配置/维护工具.py check
python 09-系统配置/维护工具.py check --sources
python 09-系统配置/维护工具.py refresh
python 09-系统配置/维护工具.py commit --input 候选状态JSON绝对路径 --expected-sha 当前状态SHA256
```

check只读；--sources会比较212个文件和新增文件哈希，报告差异，不自动重写学习资料。refresh只重算派生页面；commit验证候选和旧哈希后提交并刷新。工具不负责自动判题、推断等级或解析新增PDF，Codex必须基于实际证据做这些工作。--as-of仅用于校验，正式操作用当前北京时间，禁止用测试日期污染实际数据。

备份自动生成在库外独立目录 `D:\obsidian\backups\硬件工程师学习知识库_历史版本备份库`，不污染知识库内部检索，页面保留用户标记区外内容。每个文件原子替换，但多文件并非单一文件系统原子事务；待恢复事务标记用于识别中途中断，不能声称绝对不会丢数据。Python脚本与JSON修改前也需另做版本备份。
